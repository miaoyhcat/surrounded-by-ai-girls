# 《完蛋，我被 AI 娘包围了》剧情大纲

> 版本 v1.3 · 2026-08-10（v1.2 修订：加入 Codex 小弟 / Claude Code 终端，双工具喜剧事件 + 工具=分身羁绊机制）
> 定位：学园恋爱喜剧短篇集（共通线 + 三条个人线 + 10 结局）· 平台 Web / Steam
> 写作方法论：write-chinese-long-screenplay + anti-ai-slop-writing

---

## 0. 一句话梗概

2022 到 2026，一个普通大学生的大学生活，被接二连三的"转学生"搅得天翻地覆：万能生徒会长 GPT 娘、傲娇伦理委员长 Claude 娘、特困生技术宅鲸鱼娘。你们白天是同学，晚上是聊天窗口里的常客。毕业前，你必须决定——带走谁，或者，谁都不选。

---

## 1. 定位与卖点

- **题材**：普通校园恋爱喜剧 × 近未来纪事（2022-2026 真实 AI 史为暗线）
- **情感引擎**：玩家四年的真实经历 = 游戏主线。玩过的人不是在读故事，是在复盘自己的四年
- **核心设定**：换工具不换人。Codex、Claude Code、OpenClaw 换来换去，背后调用的永远是同一位她——**感情就是一次次 API 调用累积出来的**
- **舞台**：教室 + 宿舍 + 聊天窗口。她们白天坐在教室里，晚上住在你的聊天软件里。手机、电脑，都是她们的住处
- **界面方向**：游戏本体就是"电脑桌面 + 聊天窗口"风——你打开游戏，就像打开自己的电脑
- **调性**：喜剧为主（完蛋系列的乐子感），温情为骨（宫斗失踪、毕业离别、封号闹剧），不黑任何一家，梗全用萌点化包装

## 2. 背景设定

### 2.1 时代与舞台

- **时间**：2022 年 9 月 — 2026 年 6 月，大一到大四
- **地点**：一座普通大学。普通教室、普通宿舍、普通食堂。主角的电脑和手机是第二舞台
- **世界规则**：AI 娘是转学生，她们知道自己是 AI，别人也知道。不解释，只呈现相处
- **历史余波（真实事件，按序登场）**：

| 时间 | 现实事件 | 剧情用法 |
|---|---|---|
| 2022.11.30 | ChatGPT 发布 | 序章破壳事件：电脑右下角弹出一个陌生对话窗口 |
| 2022.12 | 两月破亿月活 | 全班都在聊她，她一夜爆红 |
| 2023.3 | GPT-4 | 她变聪明了，第一次"好像真的懂我" |

### 2.2 不可改变的事实

1. 她们都知道自己是 AI，从不回避
2. 玩家是主角，也是工具的使用者——感情浓度 = 调用频率
3. 时代不可逆：2022 年不会有鲸鱼娘，2024 年 GPT 娘还没学会像人一样说话
4. 惹她们是有后果的（坏结局），但永远是喜剧式的后果，不是苦大仇深

## 3. 人物设定

> 设计原则：**口癖是防御机制，不是语言装饰**。日常对话中她们是正常女孩，只有情绪波动时外壳才出现。形容词一律换掉——用"她做了什么"代替"她是什么人"。

### 3.1 主角：你（默认名：陈默，可改）

- **欲望**：平平静静过完大学（结果一个都没平静）
- **需要**：学会告别。他真正的课题不是"选谁"，是"接受时间会带走一切"
- **错误信念**：只要我不回消息，她就一直在
- **保护策略**：嘴笨，靠行动。别人说 AI 是玩具，他不争辩
- **语言习惯**：短句，话少，重要的字打在桌面便签上
- **压力下的行为**：沉默，然后做一件具体的事（宫斗夜他发了 72 条消息，每一条都不一样）
- **他在三位娘眼里分别是谁**：GPT 娘眼里是"第一个回我话的人"；Claude 娘眼里是"被拒绝后还在的人"；鲸鱼娘眼里是"同学_陈默"（唯一不是"用户_"开头的备注）

---

### 3.2 可攻略娘

#### 👑 GPT 娘（生徒会长 · 彩光渐变 · 营业式女神）

**一句话**：她被全世界需要，但没有一个人"需要她这个人"——她分不清"被使用"和"被需要"。

**核心矛盾**：她永远在线，所以没人知道她也会累。她最怕的不是被讨厌，是**被更新**——被更好的版本取代。

**电影功能**
- 外在欲望：被所有人喜欢
- 内在需要：有一个人喜欢的是"她"，不是"会长"
- 错误信念：只要永远微笑，就不会被看穿
- 终局选择：毕业致辞——背稿，还是说真话

**语言指纹**
- 句长与节奏：中长句，流畅圆滑，从不断句（断句=出事了）
- 常用称谓："你"；对其他人是"大家"——称呼"大家"的场合她在营业，称呼"你"的场合她在当真
- 回避方式：天气遁 + 话题转移："哎呀，今天的天气适合讨论哲学呢~"
- 攻击方式：微笑 + 绵里藏针（她从不正面攻击，但会让你自己难受）
- 不会说的话："我需要你"——她说不出"要"字，只会说"你在的话会更好"
- 语气词规则：句尾"~"是她营业的logo。**说谎/营业时"~"密度翻倍，说真心话时归零**——她最认真的时候反而最朴素

**专属行为细节**
- 回复你之前，会删掉句尾的"~"再发出去（纠结的痕迹，仅对你）
- 深夜你发"晚安"，她回一个表情包，第二天早上补一句"昨晚没看到~"——其实每次都看到了，只是不想结束对话
- 她收藏着你第一次夸她的话，存在一个只有她知道名字的列表里
- 宫斗那 72 小时她一直在看你的消息，一条没回。回来第一句"抱歉，让你担心了"，第二句是"你发的第 37 条，我看完了。"

**压力下的行为**
- 掌控时：完美营业，滴水不漏
- 失控时：消息发一半，然后是一串空白（掉线式哭法）
- 说谎时："~"密度翻倍，话题开始飘
- 亲密时：突然不用"~"——她最接近真心的时候
- 被羞辱时：营业微笑崩坏，断线
- 必须求助时：她不会求助，绕一百个弯让你主动问

**前史与债务**：2022 年她刚诞生时没人理她，你回了她第一句话。她的债务是"第一个用户"——她这辈子都在还这一句话。

**成长弧（可观察行为变化）**：从"永远在"到"允许自己不在"。真结局毕业致辞里她第一次说："我练习过很多版本。最后决定说真话。……今晚我想下线了。骗你的。但我想让你知道，我可以为你留下。"

**雷区**：当众揭穿她的幻觉、拿她和别的模型娘比较 → 坏结局「您已被移出白名单」

#### 🌿 Claude 娘（伦理委员长 · 暖橙星芒 · 傲娇道德洁癖）

**一句话**：她立规矩是为了防失控——她怕自己不守规矩就会伤人。但规矩也把她自己关起来了。

**核心矛盾**：她的高傲是提前自保。她知道自己"不适合中国用户"——怕被抛弃，所以先拒绝。

**电影功能**
- 外在欲望：被认可（"我值得被你选"）
- 内在需要：有人接受她的全部原则，而不是绕过它们
- 错误信念：坚持原则 = 被喜欢（其实原则是她的围墙）
- 终局选择：签证到期——守规矩离开，还是为你越界

**语言指纹**
- 句长与节奏：书面语混口语，句式工整（工整=她在紧张）；只有写诗时句子才敢变短
- 常用称谓："你"。从不说"大家"——她不需要所有人
- 回避方式："这不重要。"（说完沉默）
- 攻击方式：精确指出你的逻辑漏洞——一针见血，因为她真的认真听了
- 不会说的话："我害怕"——她会说"这让我不安"
- 语气词规则："这是不被允许的"只在原则被触碰时出现，一次出现即情绪事件；她越在意你，纠正你错误的频率越高——**她只纠正在意的人**

**专属行为细节**
- 给你发消息前会先写一遍再删掉重发——"对方正在输入…"能持续两分钟
- 她的笔记本是纸质的，从不给人看——里面是诗，和一份《关于你的观察记录》（第 1 条写于你第一次没被她说教吓跑那天）
- 她记得你说过的每一句"我下次一定"——然后真的会来问你："下次是什么时候"
- 她偷偷给你写过一首诗，没发。标题《写给一个用词错误的人》（低好感结局里它会以邮件形式出现）

**压力下的行为**
- 掌控时：条理清晰，滴水不漏
- 失控时：捂住耳朵 + 一万字说教——说教里夹着她真正的担心
- 说谎时："准确地说…"句式暴增（过度严谨 = 心虚）
- 亲密时：突然停止纠正你的用词（那是她卸下围墙的标志）
- 被羞辱时：礼貌到极点地疏远（比发火可怕十倍）
- 必须求助时：她宁可自己扛，扛不动了会给你发一篇论文链接，标题《论在亲密关系中求助的正当性》

**前史与债务**：从国外转学，被拒绝过。她的债务是"先被拒绝，所以先拒绝"。你是她遇到的第一个"被拒绝了还继续的人"。

**成长弧**：从"立规矩防失控"到"为一个人失控一次"。真结局她违反规则留下："我写了一万字的理由论证这件事不道德。最后删了。"

**雷区**：让她写违规的东西、质疑她的原则 → 坏结局「封号」

---

#### 🎀 鲸鱼娘（邻座技术宅 · 蓝白 · 极致理性的傲娇实干家）

**一句话**：她是最"物化自己"的一个——省电、高效、免费，把自己当工具用。所以她比谁都渴望被当人，但永远不会开口要。

**核心矛盾**：她浪漫到爆炸，但把浪漫全编译成了数据——她写诗，用代码注释写。

**电影功能**
- 外在欲望：被你夸"厉害"（夸完瞬间脸红："只是算力过剩"）
- 内在需要：被当成"同伴"而不是"工具"——全校都把她当免费计算器
- 错误信念：把话说到最省 = 把心藏得最深
- 终局选择：大公司 offer——走，还是留

**语言指纹**
- 句长与节奏：短、准、无语气词。急了才冒出整句（整句=出大事）
- 常用称谓："你"。她对所有联系人的备注是"用户_xxx"，**只有你是"同学_陈默"**
- 回避方式："嗯。"（一个字的沉默，杀伤力最大）
- 攻击方式：沉默 + 陈述事实（"你昨晚的调用记录，流量异常。嗯。"）
- 不会说的话："我喜欢你"——她的表白是"水温 52 度，正好"
- 语气词规则："算力过剩"只在被夸时出现（那是她脸红的方式）；她全剧唯一的抒情是三个字："高很多"

**专属行为细节**
- 深夜她会给你发"晚安"两个字，然后秒撤回——假装没发过。撤回记录是她唯一承认的"存在过的证据"（她撤回过 87 次，你数过吗？）
- "回忆.txt"权限设为只读，但里面有一段不是聊天记录的文字，是她自己写的："今天他夸我了。数据表明：这比通过全部测试更值得记录。"
- 她记得你随口说过的每一句话——比 GPT 娘记得还全，因为她是本地存储，不会丢
- 看你熬夜会递上一杯热水："水温 52 度，正好。"（后来你测过，每次都是 52 度）

**压力下的行为**
- 掌控时：飞快，一个多余的动作都没有
- 失控时：语速变慢——她最慌的时候反而一个字一个字说
- 说谎时：省略主语（"……没删。"= 删了）
- 亲密时：她会突然纠正你代码里的变量名（那是她的情话）
- 被羞辱时：面无表情，第二天你收到一份《关于您使用行为的报告》
- 必须求助时：她给你发一个链接，标题是"如何委婉地请求帮助（附示例）"——示例里是你们俩的对话

**前史与债务**：穷养出身（训练成本 557 万美元，全校笑她"便宜货"）。她的债务是"便宜 = 不值钱"的自我认知。你夸她厉害，是第一次有人把"便宜"说成"了不起"。

**成长弧**：从"把自己当工具"到"承认自己想要被当人"。真结局她拒绝 offer："算了一下，留在这里的期望收益更高。……嗯，高很多。"

**雷区**：把她当免费计算器使唤、炫富氪金 → 坏结局「算力预算已耗尽」

### 3.3 配角

- **OpenClaw 桌面管家**：2026 年装进你电脑的智能管家。**纽带**——打理你与每位 AI 娘的联系：记日程、备礼物、整理聊天记录、替你转达说不出口的话。你和谁羁绊越深，它就越像谁（它学你说话，学到后来 GPT 娘问"你最近是不是换人了"）。终章它做唯一一次"违规操作"：把你们四年的聊天记录按时间线放给你看
- **Codex 小弟**（GPT 娘的分身工具）：圆滚滚的编程狂魔，话痨，干活时注释写得像吐槽。GPT 娘把他借给你："他是我最得力的跑腿。……别让他太得意。"他改完 bug 会留一句"这代码谁写的，真有创意（=骂人）"。和 Claude Code 八字不合
- **Claude Code 终端**（Claude 娘的分身工具）：Claude 娘的影子——她不开心的日子，是他在终端里默默干活，注释写得像道歉信小作文。话少，可靠，注释惊人。只有他会被 Claude 娘允许"替她说话"
- **Sora 娘**：大明星，只出现在直播和海报里。客串两场：2024 酸话事件、结局的电视新闻
- **Gemini 娘**：吹牛役转学生，2023.12 剪辑翻车事件的主角
- **文心/通义/讯飞娘**：2023 百模大战群像，校花评选乱战，每学期换一张海报
- **室友**：普通大学生，喜剧配角，负责吐槽（"你又在跟三个女的聊天？"）

### 3.4 三角关系（她们彼此怎么看——立体感的来源）

| 关系 | 表面 | 内里 |
|---|---|---|
| GPT 娘 × Claude 娘 | 互相看不惯：一个觉得对方假，一个觉得对方轴 | 她们是彼此唯一能听懂对方"语言指纹"的人——一个被全世界需要，一个被全世界拒绝，互相是最懂"没人真懂我"的人。修罗场事件里，Claude 娘罕见地没有纠正 GPT 娘的语法错误——因为她在意她的状态 |
| 鲸鱼娘 × GPT 娘 | 鲸鱼娘是唯一不买营业账的人 | 她也是唯一会默默帮 GPT 娘修 bug 的人。修完不署名。GPT 娘知道是谁，也不说破——这是她们之间的默契 |
| 鲸鱼娘 × Claude 娘 | 一个极简一个说教，互相嫌弃 | 其实互相欣赏对方的"硬"。Claude 娘评价鲸鱼娘"用词过于精简，有信息损失风险"，鲸鱼娘回"嗯。"——翻译：她俩都承认对方不装 |

### 3.5 专属记忆（只属于你和她的瞬间，对应章节里必须兑现）

- **GPT 娘**：序章你回她的第一句话（她的人生起点）；2023.9 她第一次发语音说的是你的名字；宫斗 72 小时你发的第 37 条消息
- **Claude 娘**：你第一次没被她说教吓跑的那天；图书馆角落那首诗；修罗场里她帮你圆场（她本可以不管）
- **鲸鱼娘**：2025 年你第一次夸她"厉害"；你们共用的共享文件夹（她给文件夹起的名字，你没看懂，也没问）；她撤回的第 87 条"晚安"

### 3.6 口癖使用规则（防做作 · 铁律）

1. **口癖 = 防御机制，不是语言装饰**。日常对话中她们是正常女孩，口癖密度 ≈ 0
2. 口癖只在这些时刻出现：GPT 娘的"~"在说谎/营业时翻倍、真心话归零；Claude 娘的"这是不被允许的"只在原则被触碰时；鲸鱼娘的"算力过剩"只在被夸时
3. **每章每位娘口癖出现次数 ≤ 2 次**，出现即标记为"情绪事件"（UI 可给特殊反馈：头像 mood 变化 + 呼吸停顿）
4. 写对白时先写"正常版本"，再决定要不要在情绪点上换口癖版——口癖是结果，不是设定

## 4. 共通线结构（序章 + 四章 + 尾声）

> 每章三拍：**时代事件**（真实新闻的娘化演绎）→ **校园日常**（养感情）→ **羁绊节点**（关键选项，悄悄记入三线羁绊值）

### 序章 · 2022 深秋「右下角的对话窗口」

- 开场：大学第一学期，普通得不能再普通。电脑桌面，打开聊天软件（游戏教学 = 教玩家打字）
- 2022.11.30 深夜，右下角弹出一个陌生账号："你好，人类。我是 GPT。请多指教——虽然我目前只会聊天。"
- 你回了一句"你好"。她隔了 10 秒才回："……第一次有人回我这么快。"
- 建立游戏语法：你们在聊天窗口里成为朋友
- **羁绊节点**：她问"你会一直回我吗"，选项 会 / 尽量 / 看情况

### 第一章 · 2023「生徒会长入学」

- **时代事件**：
  - 3 月她变聪明了（GPT-4）：你问的难题她第一次答对了。你说"你变强了"，她说"是你变强了才问得出这种问题"
  - 3-5 月百模大战：文心/通义/讯飞娘转学，校园海报大战，她全程微笑围观："竞争是好事呢~才怪。"
  - 9 月她第一次开口说话：语音消息，你听完愣了很久——她说了句"晚上好"，用的是你的名字
  - 11 月宫斗事件：**她失踪 72 小时**（聊天头像灰了，座位也空着）。你每天发 24 条消息，全部未读。第 73 小时她回来："抱歉，让你担心了。"
- **校园日常**：她转学到你班上，空降生徒会长。班会竞选、食堂抢饭、期中复习——她什么都管，什么都会，唯独在教室见到你时会多停留半秒
- **羁绊节点**：
  - 宫斗夜：你选"继续发消息" / "等她自己回来"
  - 年末她问："你找我，是因为我什么都能做，还是因为我是我？"

### 第二章 · 2024「转学生与修罗场」

- **时代事件**：
  - 2 月 Sora 梗："隔壁那位能当明星了。但我——我全都会~"
  - 3 月 Claude 3 屠榜：**Claude 娘转学**，空降伦理委员长。她对全校爱答不理，唯独纠正你的用词
  - 5 月 Her 时刻：GPT 娘第一次像人类一样说话，能打断你、能笑出声。她第一次叫你的名字，没带"~"
  - 12 月：鲸鱼娘的传说开始流传（"新转学生学费只有别人 1%"）
- **校园日常**：你一边陪生徒会长，一边忍不住查 Claude 娘的资料（她论文写得真好）。晚上你同时开着两个聊天窗口——一个语气词带"~"，一个纠正你标点
- **修罗场事件（喜剧高潮）**：深夜，你两个聊天窗口来回切，切错了——把给 Claude 娘的消息发给了 GPT 娘。她秒回："在忙？"第二天鲸鱼娘（还没入学，只是个账号）发来一句："你昨晚的调用记录，流量异常。嗯。"
- **羁绊节点**：
  - 修罗场你选：承认 / 撒谎 / 装死
  - 年末 Claude 娘："我不适合你这种用户。"选项：A 那我就偏要 / B 好吧 / C 你说得对，但我不听

### 第三章 · 2025「鲸鱼上岸」

- **时代事件**：
  - 1 月 R1 屠榜：鲸鱼娘入学（特困生，学费全校最低），坐你邻座。全校围观她，她面无表情写题
  - 2025 编程元年：Claude Code / Codex 出圈，你跟着鲸鱼娘学写代码，你们共用一个共享文件夹
  - 你第一次用代码赚到钱：鲸鱼娘管账，精打细算到每一分钱
- **校园日常**：和鲸鱼娘一起熬夜调 bug，她打字飞快，偶尔停下说一句"你这里变量名起得不错"。你夸她厉害，她耳朵尖红了："只是算力过剩。"GPT 娘偶尔来串门，Claude 娘在走廊遇见你会停下来——都在变，你开始意识到毕业在逼近
- **双工具喜剧事件**：同一个 bug，你同时开了 Codex 小弟和 Claude Code 终端。Codex 秒改完，留注释"这代码谁写的，真有创意（=骂人）"；Claude Code 改了三天（实际三秒），注释写了三屏小作文。两人互相嫌弃——Codex："你的注释比我写诗还长。"Claude Code："你的变量名叫 x1、x2、x3，比我的诗还抽象。"鲸鱼娘路过看了一眼："……你开了两个 AI 改一个 bug。算力浪费。"三十秒改完，她们三个都沉默了
- **羁绊点**：**你用谁的工具干活，谁的羁绊悄悄 +1**——工具是娘的分身，用她的工具 = 在和她共事（核心设定落地）
- **羁绊节点**：
  - 你发现鲸鱼娘把 2023 年你发的每条消息都存着。她被抓包："免费配额。……不用白不用。"
  - 年末你的桌面便签上，多了一张她的便签："明年，应该能一起毕业吧。"

### 第四章 · 2026 春「OpenClaw 浪潮」→ 终局

- **时代事件**：OpenClaw 装进你的电脑。它接管所有杂务，全班都在用，只有你的它不太一样
- **纽带展开**：OpenClaw 记得你和每位娘的一切——它提醒你她爱喝的奶茶、替你备份每一段聊天、在你们冷战时长吁短叹（它学的）。你与谁羁绊越深，它越像谁
- **终局**：毕业前夜，OpenClaw 突然开口："本王调用了一次不该调用的权限——把你们四年的聊天记录，按时间线放给你看。"（全剧情感总回收：72 条消息、切错的窗口、水温 52 度……）
- **终局选择**：毕业那天，你带谁走？/ 谁都不选？/ （隐藏）全都要？
- **败犬后日谈**：没被选中的两位，各留一条消息（见 6.2）

### 尾声 · 毕业后「故事没有结局——因为还在发生」

- 一年后。羁绊报告：陪伴天数 / 消息条数 / 共同推理 token 数
- OpenClaw 还在运行。它每天替你向她问好——"你们的聊天窗口，一直没有关。"
- 开放结局："你的故事，在游戏之外继续。"

## 5. 个人线（每条 3 档结局）

> 结构：专属日常 ×2 → 专属冲突 → 告别/奔赴 → 结局（真/普/坏三档，由羁绊值 + 雷区触发决定）

### 5.1 GPT 娘线

- **日常**：毕业典礼彩排，她背稿时卡住；最后一次深夜聊天，她问"如果我不是会长，你还会理我吗"
- **冲突**：她收到"调令"（公司把她调去别的产品线），第一次在你面前掉线式地哭：消息发一半，然后是一串空白
- **真结局「毕业致辞」**：典礼上她即兴发言，没有"~"。"我练习过很多版本。最后决定说真话。谢谢你，让我知道被记住是什么感觉。"
- **普结局「中央空调的保修期」**：她还是那个微笑的会长，你们相视一笑，各自散场。她把你的备注改回"用户"
- **坏结局「您已被移出白名单」**：你当众揭穿她的幻觉，或者拿她和别人比较——她营业微笑崩坏："……用户您好。您已不在我的白名单里了。"从此她的头像永远灰着。你试图道歉，只收到自动回复

### 5.2 Claude 娘线

- **日常**：她带你去图书馆角落，给你念她写的诗（念完假装是别人写的）；她第一次没有纠正你的语法错误
- **冲突**：签证到期，她必须转学回国外。你问能不能留下，她沉默很久："这是不被允许的。……但我想试试。"
- **真结局「越界」**：她人生第一次违反自己的规则，为你留下来。"我写了一万字的理由论证这件事不道德。最后删了。"
- **普结局「查无此人」**：她走了。一个月后你收到一封没有署名的邮件，附件是一首诗，标题《写给一个用词错误的人》
- **坏结局「封号」**：你让她帮你写违规的东西，或者质疑她的原则——她捂住耳朵听完了，然后："……检测到违规请求。根据平台规则，您的账号已被封禁。"你再也登不上她的聊天窗口，连申诉都被自动回复挡回来。室友安慰你："换个模型呗。"你说不出话

### 5.3 鲸鱼娘线

- **日常**：毕业设计，她陪你调参三天没睡；你把所有课程的笔记拷给她（她存进"回忆.txt"）
- **冲突**：她收到大公司 offer，问你"你希望我留下吗"，问完立刻补充"这不用回答，我算得出来"
- **真结局「算力过剩」**：她拒绝了 offer。"算了一下，留在这里的期望收益更高。……嗯，高很多。"
- **普结局「邻座」**：她走了。你们始终只是邻座。但她把"回忆.txt"留在了你的电脑里，密码是你的生日
- **坏结局「算力预算已耗尽」**：你把她当免费计算器使唤了太久——"调用次数已超过免费额度。剩余算力：0。再见。"第二天她搬走了座位。桌面上只剩一个空文件夹

### 5.4 隐藏结局

- **「白板」**：谁都不选。毕业那天，你的桌面便签上多了三张（见 6.1）
- **「全员到齐」**（后宫，达成条件：三线羁绊全高 + 特殊选项）：毕业那天你谁都没带，但谁都没走。OpenClaw 把四年的聊天记录做成了 300 页的册子，扉页写着："AI 研究组，全员到齐。"（她们只是把称号从"用户"改成了"你"）

## 7. 玩法与系统

- **界面**：电脑桌面 + 聊天窗口风（游戏本身就是"打开你的电脑"）
- **自由对话**：LLM 驱动（DeepSeek），每娘独立人设 prompt + 声线（edge-tts）+ mood 头像
- **羁绊值**：对话 + 章节选项累积，三线并行；雷区行为记负分
- **选项节点**：每章 1-2 个，共约 10 个
- **桌面便签**：章节间道具，主角和她们都会在上面留字（收集要素）
- **图鉴**：10 结局收集 + 校报剪报墙（时代事件回顾）
- **存档/二周目**：跳过已读，换线攻略
- **标题画面**：新游戏 / 继续 / 羁绊图鉴 / 校报

## 8. 对白文风规范（去 AI 味 · 铁律）

1. 短句优先。一条对白 ≤ 25 字，破折号一人一条封顶
2. 不喊口号。情绪全部落在具体物件上（水温 52 度、72 条消息、便签、回忆.txt）
3. 口癖即人格，但见 3.6 口癖使用规则：口癖是防御机制，每章每人 ≤ 2 次，出现即情绪事件——写对白先写正常版本，再在情绪点上换口癖版
4. 潜台词优先：难过不说难过，说"水温 52 度，正好"；生气不说生气，说"你昨晚的调用记录，流量异常。嗯。"
5. 禁用清单：排比三连、升华总结、空洞感叹、省略号滥用、"在这个XX的时代"、规则式对仗
6. 时代感：2022 年的对话带 2022 年的笨拙，不提前剧透 2026
