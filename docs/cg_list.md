# CG 插画清单（给画师）

> 规格统一建议：**事件 CG 横版 16:9（≥1920 宽）；头像/卡片竖版 3:4 或 4:5（≥1024 宽）**；PNG 优先。
> 画风三娘统一；配色基准：鲸鱼蓝白 / GPT 白绿 / Claude 暖橙。

## 必做 · 头像（3 张）—— 有这些就能开玩

| # | 角色 | 内容 |
|---|---|---|
| 1 | 鲸鱼娘 | 半身/头像，蓝白、鲸鱼元素（尾鳍发饰），平静微抿嘴 |
| 2 | GPT 娘 | 半身/头像，白绿、花环元素，营业微笑、闪亮大眼 |
| 3 | Claude 娘 | 半身/头像，暖橙、星芒 ✳ 元素，认真抿嘴、长睫毛 |

## 共通线事件 CG（6 张，横版 16:9）

| # | 场景 | 画面内容 | 情绪 |
|---|---|---|---|
| 4 | 标题画面 | 三娘合照或游戏氛围图（深夜电脑桌） | 招牌感 |
| 5 | 序章·右下角的对话窗口（2022 深夜） | 电脑桌面特写，右下角陌生聊天窗口弹出，光标闪烁，窗外夜色；浮字"你好，人类。我是 GPT。" | 安静/好奇 |
| 6 | 宫斗之夜·72 小时（2023.11） | 深夜宿舍，屏幕灰暗头像 + 满屏未读消息（72 条），手停在键盘上 | 泪点/空旷，偏冷色 |
| 7 | 修罗场·切错的窗口（2024） | 同一屏幕两个聊天窗口并排——句尾带"~" vs 措辞工整，光标悬在发送键 | 喜剧 |
| 8 | 鲸鱼上岸·爆红（2025） | 教室角落，鲸鱼娘面无表情写题，周围人群围观举手机，只有邻座你在看她 | 围观与孤岛 |
| 9 | OpenClaw 时间线回放（2026 终局） | 深夜，四年聊天记录像星河按时间轴飞过，屏幕光照脸上 | 全剧情感总回收 |

## 个人线 CG（3-4 张，推荐）

| 线 | 场景 | 画面内容 |
|---|---|---|
| GPT | 毕业致辞 | 礼堂台上她没拿稿子，第一次没有"~"；台下仰望。暖色 |
| Claude | 图书馆角落 | 她念诗，假装是别人写的；桌上一杯茶、一本从不给人看的笔记本 |
| 鲸鱼 | 凌晨的共享文件夹 | 两台电脑并排同一项目，桌上一杯热水（52 度）、一沓笔记，凌晨蓝光 |

## 结局卡（10 张 → 最低 3 张复用）

- 每个结局一张"定格瞬间"，竖版 4:5
- 最低方案：每娘 1 张通用结局图（高好感向），低好感/坏结局先用"头像+文字排版"顶住
- 结局清单见 `docs/outline.md` 第 6 节

## 可选（后补）

- 全身立绘 ×3（标题/结局页震撼感）
- 桌面壁纸 ×3（每娘一款聊天背景）
- 配角图标：OpenClaw 校工 / Codex 小弟 / Claude Code 终端（几何小图标，可由程序侧 SVG 顶替）
