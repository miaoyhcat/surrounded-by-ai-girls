# 《完蛋，我被 AI 娘包围了》美术管线方案

> v1.0 · 2026-08-10 · 待形象调研结果填入

## 0. 结论先行

**用流传最广的形象做基准，我们自己重绘**——不直接搬同人图（同人图有版权，Steam 上架会被举报下架），但所有标志元素原样保留：看到就是她，又不怕被锤。画风统一成我们自己的，正好成为游戏 IP。

## 1. 形象基准（定稿 · 来源：B站流传形象视觉拆解 + logo 铁律）

> 调研样本：B站「当大模型们有了各自的娘化梗图」22 万播放全家福、鲸鱼娘西丝特（VUP，单视频 150 万播放）、DeepSeek 小女仆系列（GPT 小龙娘）、「可爱的 ChatGPT 娘」等多源交叉验证。

绘制路线：以本表为基准**原创重绘**（自己画，画风统一），不使用任何单张同人图。

## 2. 版权处理策略

1. 同人图版权归原画师，直接使用 = 上架风险
2. 我们的做法：**要素致敬 + 原创重绘**——logo 元素（鲸鱼/花环/星芒）是品牌图形，不受同人画师版权约束；人物造型（发型/配色/气质）以流传形象为参考基准重新绘制
3. 游戏名、角色名、对白全是原创，不碰任何一家官方的名字侵权线（"鲸鱼娘"等昵称是社区通用称呼）
4. 如果将来 Steam 上线前想用原图，再谈授权或约稿（备选方案，成本高）

## 3. 管线分层

### 3.1 头像系统（MVP 核心 · SVG 手绘）
- 每娘 1 个主头像 + 7 个 mood 表情状态：happy / shy / sad / neutral / excited / pout / love
- SVG 矢量，表情由眼睛/嘴/腮红/发丝细节切换（mood 变化有动画过渡）
- 聊天窗口头像 + 心情气泡 + 打字中状态
- 产出：static/avatars/{id}_{mood}.svg

### 3.2 立绘/插画（Seedream 生成）
- 生图铁律：只用 Seedream（不用 AutoClaw/智谱清言）
- 需要的素材：
  - 每娘 1 张半身立绘（标题画面/结局卡用）
  - 章节事件插画 ×8（宫斗之夜、修罗场、双工具事件、毕业典礼……）
  - 结局卡 ×10（7 结局 + 3 张）
- 需要用户提供 Seedream API key（环境变量传入，不写文件）

### 3.3 UI/背景（CSS + SVG）
- 界面方向已定：**电脑桌面 + 聊天窗口**风
- 桌面壁纸：深夜渐变 + 星星 + 图标阵列（OpenClaw 图标、Codex 图标、Claude Code 终端图标、回忆.txt……）
- 聊天窗口：三位娘各自的主题色皮肤（彩光渐变 / 暖橙 / 蓝白）
- 章节标题卡：复古校报风（呼应新闻事件）
- 白板→桌面便签：便利贴元素，可收集

### 3.4 动态/演出
- 对话打字机 + 光标
- 语音：edge-tts 每娘一声线（已有管线）
- 标题画面 + 结尾卡：CSS 动画（参考 video-shotcraft 审美规则：呼吸、留白、单主角）

## 4. 产出顺序（大纲定稿后）

1. 头像 SVG ×3 娘 × 7 mood（我手绘）
2. 聊天窗口 UI + 桌面场景（CSS）
3. 立绘/插画等 Seedream key 到位后生成
4. 校报/便签/图标等小件随剧情走

## 6. 艺术方向（v3.0 同居日常版 · 用户定）

**功夫兔和菜包狗式**：
- 扁平 2D 卡通风：简洁线条、色块分明、不加厚重渲染——Q 版小人像"会动的贴纸"
- 暖色日常：黄昏、台灯、键盘背光，生活感优先于华丽
- 喜剧构图：小人在大场景里的比例反差就是笑点（键盘跑酷/咖啡杯边蜷着/窗台晃腿）
- 真实照片 + 扁平小人合成（画师路线不变）
- 动画参考：动作夸张但克制，情绪靠姿势不靠表情大特写
