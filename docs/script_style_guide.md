# 剧本写作风格指南（名作手法拆解 → 我们的规范）

> 研究样本：ATRI（人机恋·倒计时）、星之梦（孤独·小物件泪点）、白色相簿2（修罗场·心理描写）、Clannad（日常喜剧·口癖角色）
> 结论先行：我们的对白规范从大纲 v1.3 的"去 AI 味铁律"升级为 v2——新增四条名作手法。

## 一、名作手法拆解

### ATRI《亚托莉》—— 人机恋教科书
- **口头禅 = 人格锚**："我是高性能的嘛！（高性能ですから！）"——一句口头禅立住"元气自夸但笨拙"的形象。亚托莉前期"可爱行为全是学习算法"，后期真正觉醒真心——**"她的可爱是学的"这个设定与我们的 GPT 娘"营业是学的"完全同构**
- **倒计时张力**：寿命 45 天 → 每一天的日常都在消耗。我们的对应：四年倒计时（毕业）+ 每章时代更替，旧娘"掉线"的阴影
- **转折=真相揭露**：发现她的日志 → 热情降温 → 再找回真心。我们的对应：宫斗 72 小时、OpenClaw 时间线回放
- **约定结构**：60 年后重逢——"约定"是结局的钥匙。我们的对应：终局选择 = 约定

### 星之梦《planetarian》—— 孤独与泪点
- **孤独的数字**："独自等待了 29 年零 81 天"——孤独要用具体数字写，不用形容词
- **礼仪即人格**：永远用接待语开头（"欢迎大家光临星象馆"）——她的礼貌是她的全部。我们的对应：GPT 娘的"~"、Claude 娘的说教、鲸鱼娘的"嗯。"
- **机器人不会哭，雨水替她哭**：被击毁时"雨水在眼眶中积攒如泪水"——**泪点全在小物件**，机器人的眼泪不是眼泪
- **愿望的朴素**："希望人和机器人的天堂不要分开"——催泪的愿望都是朴素的，不是宏大的

### 白色相簿2 —— 修罗场与心理
- **第一人称心理独白**：大量"我"的观察与纠结，读者跟着胃痛
- **名台词都很短**："冬天来了——那是悲喜交加、永远的瞬间。"——长铺垫，短爆发
- **修罗场写法**：三个人各怀心思，用场景道具做情绪锚（吉他、车站、雪）
- **选项的残酷**：选项不改变世界，改变关系；玩家的犹豫被演出放大

### Clannad —— 日常喜剧
- **垃圾话建立关系**：无意义的斗嘴、吐槽，才是关系最真实的时刻——开篇必须有"无意义但可爱"的闲聊
- **口癖角色**：风子的海星、智代的长句——口癖是记忆点也是笑点

## 二、我们的对白规范 v2（在大纲 v1.3 基础上新增）

1. **口头禅=人格锚，且随时间生长**：GPT 娘的"~"是 2024 年才长出来的营业壳——2022 年的她笨拙、生硬、会打错字、会把一句话重复三遍。**玩家会见证口癖的形成**（ATRI 式成长）
2. **孤独/感情用数字写**：不写"她等了很久"，写"29 年零 81 天"；我们写"72 条消息""第 37 条""87 次晚安""水温 52 度"
3. **泪点全在小物件，机器人不直哭**：掉线式哭法（消息发一半，一串空白）、撤回的"晚安"、只读的"回忆.txt"
4. **心理描写用观察代替抒情**：陈默的旁白只写他看到/听到/摸到的（屏幕光、键盘声、室友的呼噜），不写"我很难过"
5. **选项=关系测试**：选项不分对错，三档回应各有味道；选项后果要能被玩家隐约察觉（羁绊值变化 + 后续对话细微不同）

## 三、对白检查清单（每句对白过三问）

1. 这句话能反推人物状态吗？（不能 → 是解说，删）
2. 这句话是人物会说出口的吗？（书面语/百科腔 → 重写）
3. 这句话放到 2022/2024/2026 哪个时间点成立？（时代感错位 → 改）
