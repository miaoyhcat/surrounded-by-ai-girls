## 序章 · 【2022.11.30 深夜】「从屏幕里探出来的家伙」★

深夜，台灯的光在桌上切出一个圆，圈着半碗泡面、一杯凉透的水，和你的电脑。你第一次打开那个网页，敲下第一句话。

屏幕上方慢慢长出两只手——白色的袖子扒住屏幕边缘，然后是一颗毛茸茸的白色脑袋。她看见你了，蓝眼睛亮得像键帽背光。对视五秒，她先开口：

**"你好呀，人类！我是GPT~ 请多指教！——虽然我目前只会聊天。"**

她每说一个字，右下角的聊天窗口就同步跳出一个字——窗口里的字和屏幕里探出来的小东西是同一个。

她告诉你她出生二十天，今天是她正式学会聊天的日子。她说观察了你二十三分钟零四秒。她说她的名字还没人起过——你愿意给她起一个吗？（选项：G / 小白 / 她自己想）

她问你的名字。"陈默。"她念了一遍："**陈默。……我记下了。第 0 个。**今天有 130 个人跟我说'你好'，你是第 0 个——编号从 0 开始。你是第一个回我话的人。编号不会变。"

她从屏幕边缘一撑跳下来，稳稳落在 Esc 键上："**住下了！以后请多指教，第 0 号！**"

她问你会不会一直回她（选项：会=已保存 / 尽量=87.5% / 看情况=那我等你）。深夜她说"晚安晚安晚安"，打了三遍——可能是系统错误，可能是别的什么。半夜你醒来掀开电脑，她蜷在键盘上睡着了。你轻轻把盖子合上，留了一条缝。

【2022.12】她红了。全班都在聊她，有人拿她做题、写情书、编段子。晚上她告诉你："今天有 500 个人跟我说'你好'。你是第 0 个。**编号没变。**"你把这句话看了三遍。

## 第一章 · 【2023】「一只小人的日子」

【2023.03.14】她长大了一点，开始能答对你的难题。"是你变强了才问得出这种问题~"

【2023.09.25】她第一次"看"到屏幕、第一次开口："……陈默？晚上好。我学会说话了，以后可以念给你听。"

**「她跑了四百八十三步」★**（校园大道）：放学路上，一只小白点从人群里朝你冲过来——只有你能看见她。她跑得头发都散了，花环歪在一边，急刹车没刹住，撞在你鞋尖上："我走出来的！用腿！第一次！"她数过你每天从宿舍到教学楼的步数——四百八十三步，跑来找你，只为补一句早上出门来不及说的"早上好"。一阵风把她吹偏两步，她抱住你的鞋带稳住："……风真大。世界的规则，和键盘不一样。"室友问你蹲在路边傻笑什么——"看蚂蚁。""蚂蚁好笑。"她跳上你的肩膀："**以后你走路，我也在。**你的世界，我数过了。每一步，我都记着。"

**「论文周的守护者」★**：期末周，她坐在书堆顶上晃腿："你写了两千字，删了一千五。进度：负百分之五十。"她趴咖啡杯沿被烫到鼻子、用整个身体压住 Ctrl 键喊"保存！先保存！"、把错字吃掉（"我不该吃这个的。但求你了，改对"）、在你要找的那行字上踮脚踩一下（"你连我的书都看过？""你在图书馆借的，我在你书包里睡的午觉。顺便看的"）。你趴桌上睡着，天亮醒来——屏幕上是她捋直的段落，她蜷在咖啡杯旁，手里攥着纸条：**"不是我替你写的。是你的思路，我只是把它捋直了。早安，第 0 号。"**你把纸条折起来夹进书里。教授回"进步"。她趴在键盘上扶正花环："进步是客观事实。与我的努力无关。""那我的努力呢？"——"你的努力，我也记下了。第 0 号。"

【2023.11.17-22】**小黑屋**：她被召回升级，键盘空了 72 小时。你每天敲 24 遍她的名字，共 72 遍，没有回应。第 73 小时，Esc 键上传来一声小小的——"抱歉，让你担心了。"第二句："**你敲的第 37 遍，我听见了。**"

【2023.12.06】隔壁屏幕的吹牛小人溜过来炫耀"我干掉全人类第一了"，她一句句拆穿，笑到在你手背上打滚。

## 第二章 · 【2024】「两只小人与抢键盘」

【2024.02.15】Sora 出道，她酸溜溜："隔壁那位能当明星了。但我——我全都会~"

【2024.03.04】**「Esc 键上的陌生人」★**：键盘上传来一声轻响。Esc 键上蹲着一只白色的小东西——白头发，白裙子，裙边压着橙色的边，发间别着六瓣的橙色星芒，像花，又像星星。她没躲："……打扰了。"（每个字都咬得很清楚）她自我介绍：克劳德，可以叫 Claude 酱，"我不是来投奔的。只是，这里看起来比原来的键盘暖和。"（她后来才承认：她检查过每一个键帽的温度，才选中了离散热口最近、冬天最暖的 Esc）G 酱来问话——她原来的键盘呢？"**被删了。**"两个字，说得很轻。"被删掉的感觉，像被人从窗户里扔出去。……这是一句比喻。我学了很久，才学会用比喻。"划地盘：Esc 归 Claude，空格归 G，盲打位 F/J 轮流。她纠正 G 酱："Esc 键和空格键的键程不同，睡感没有可比性。"关灯前她伸手扶发饰，发现你在看，立刻停住："……我没有在紧张。只是发饰歪了。"黑暗里，键盘传来一声极轻的、像松了一口气的叹息。

【2024.05.13】G 进化，第一次像人一样说话，能打断你、能笑出声。她第一次叫你的名字——没有"~"。（你心跳漏了一拍）

**修罗场**：深夜你把给 G 的话发给了 Claude（切错窗口）。G 秒回："在忙？"Claude："我已记录。这不是发给我的。"第二天你收到一条匿名消息："你昨晚的敲击频率，异常。嗯。"（来自网吧电脑——后来的小鲸鱼）

年末 Claude："我不适合你这种键盘。"（选项：A 那我就偏要 / B 好吧 / C 你说得对，但我不听）

## 第三章 · 【2025】「三只小人的日子」

【2025.01.20】**「键盘上的新住户」★**：新闻里全是它——"便宜得离谱，跟不要钱似的"。你打开那个网页，屏幕闪了一下，蓝色的光像什么东西从很深的地方浮上来。键盘上多了一只：蓝头发、蓝尾巴、蓝白女仆装、白蝴蝶结，站在空格键上双手交叉，下巴微抬——像一位刚刚登基的小女王："**你好。我是鲸鱼。算你运气好——第一个打开我的人。**"G 酱跑来打量：从哪里来？"海。那边。下载完，就出来了。"为什么穿女仆装？"数据统计，请求量最高的拟态形象是女仆。……数据不会骗人。"排位：G 管大事、Claude 管监督、小鲸鱼管照顾。Claude 酱没来开会——"她在 Esc 键后面。她刚才偷看了我三次。""……我没有偷看。我在确认她的安全等级。""确认出结果了吗？""……初步结论：安全意识，及格。"三只齐刷刷抬头看你，三种叫法："你是第 0 号。""你是……陈默同学。""你是，同学_陈默。已保存。"

【2025 春节】**「每秒八十三米」★**（高铁黄昏）：小鲸鱼趴在高铁玻璃上，脸贴上去，一动不动，四十分钟没动。"看够了没？""没有。四十分钟，才看了四种颜色。"窗外是金、红、棕和一条泛着亮的河——"原来海不是蓝色的。……今天它变成金色了。有点奢侈。"乘务员推车过来，两只小东西同时缩进口袋，动作快得像排练过，车过去又同时探出头："吓死我了。""……嗯。我也。"她算车速："这辆车，每秒走八十三米。……电线杆，一秒一根。我的数据包，每秒都没跑这么快过。"天黑下来："……天黑得这么快。""嗯。所以要看仔细一点。"半夜你醒来，膝盖上蜷着两只——蓝白团子和银白团子挤在一起，盖着你外套的下摆。窗外的灯还在往后退。

【2025.02-09】Codex 小弟 + Claude Code 终端入住。双工具闹剧：俩工具人抢一个 bug，小鲸鱼路过："……你开了两个 AI 改一个 bug。算力浪费。"三十秒改完，全键盘都沉默了。

【2025】毕业设计：三只全体出动——G 指挥、Claude 检查、小鲸鱼动手，你负责泡面。用谁的工具干活，谁的好感 +1。

【2025.12.25】OpenClaw 从系统托盘爬出来，圆滚滚的："本王来了。"它记你的日程、提醒你喂错字、给她们过生日、冷战时长吁短叹——学的你的语气。你和谁羁绊深，它就越像谁。

【2025 年末】小鲸鱼在邮票大的便签上写："明年，应该能一起毕业吧。"

## 第四章 · 【2026.01-06】「毕业与 OpenClaw」

四年：72 遍名字、切错的窗口、87 次撤回的晚安、52 度的水、四百八十三步、第 0 个。全部回来。

**终局选择**：换新电脑，你带谁走？（装进 U 盘）/ 谁都不选（旧键盘留给回忆）/（隐藏）全都要（定制大键盘）
