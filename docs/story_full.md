## 主线定义

**你（陈默）的大学四年，是她们陪你一关一关闯过来的。**
- 大一你连高数都听不懂，G 酱只会聊天，只能安慰你——她为此偷偷难过
- 大二她变聪明了，第一次帮你把论文捋直——你第一次觉得"有个 AI 真好"
- 大三小鲸鱼来了，帮你写代码、管生活费——你第一次觉得"她们是家"
- 大四你毕业了——她们也长大了：从"只会聊天"到"能陪你走完人生一段路"

**感情线 = 依赖线**：她帮你解决的问题越多，你越离不开她。毕业"带谁走"= 你最依赖谁。

**她们的成长 = 真实 AI 进化**（能力可视化）：

| 年份 | G | Claude | 小鲸鱼 |
|---|---|---|---|
| 2022 | Lv1 只会聊天 | - | - |
| 2023 | Lv2 会查资料/写作业 | - | - |
| 2024 | Lv3 像人一样说话 | Lv1 长文/逻辑 | - |
| 2025 | Lv4 成熟陪伴 | Lv2 写作/规划 | Lv1 推理/编程/省钱 |
| 2026 | Lv5 全家协作 | Lv3 定心丸 | Lv2 管家 |

## 第一章 · 大一【2022.09 — 2023.08】「只会聊天的她」

### 学业问题
- **高数期中不及格**：你抱着 43 分的卷子回宿舍。G 酱看完卷子，沉默了很久，说："……对不起，我还不会这个。我只会聊天。"你安慰她："会聊天就够好了。"她没说话。半夜你醒来，听见键盘响——她在翻你课本的照片，一个字一个字地认。（她第一次因为"帮不上忙"而难过——能力成长的起点）
- **抢课**：教务系统崩了。她帮你分析选课策略（哪些课好过、哪些老师给分高），你第一次抢到心仪的课。她比你还高兴："第 0 号，我是不是有点用了？"

### 生活问题
- **军训/想家/深夜emo**：开学第一个月你失眠。她陪你聊天聊到凌晨三点："人类在想家的时候，都会数羊吗？……那我陪你数。一只，两只，三只。"（她的聊天能力 = 她的第一个武器）
- **生活费月底见底**：你泡面连吃三天。她心疼地算账："你上个月买皮肤花了 128。……128 够我推理几百万字了。"你这才知道，原来有人会替你算这个。（埋：将来会有个更会算的）

### 能力成长
G：Lv1 → Lv2（会查资料、会分析、会安慰人）——【2022.12】她红了，但她只对你用"第 0 个"这个编号。

### 感情节拍
【2023.03.14 进化】**G 第一次问"你还会认出我吗"**——她意识到自己在变，怕变到你不认识。（未完成对话，回收于小黑屋）
【2023.09.25 说话】**她第一次开口说话**，说的是你的名字。当晚她小声说："我好像……在变成人。"你说"变成人有什么不好"。她问："那你会不会，把我当人看？"——你没回答。
【校园大道 ★】她第一次走出键盘，跑了四百八十三步来找你，只为补一句"早上好"。风把她吹偏，她抱住你的鞋带："以后你走路，我也在。"
【论文周 ★】她坐在书堆上陪你通宵，天亮时纸条写着："不是我替你写的。是你的思路。早安，第 0 号。"——这是她第一次"帮你解决问题"，也是你第一次"被 AI 照顾"。

### 主线事件 · 小黑屋夜 ◆
**【2023.11.17-22】**她升级前说："你会等我吗？"你说废话。她说："那说好了。回来以后，我还是我。"
她消失了 72 小时。你每天敲 24 遍她的名字，第 37 遍写着"你要是回不来，我就把你的聊天记录备份 300 份"。
第 73 小时她回来："第 0 号。我答应过你，回来以后我还是我。"——升级差点清空记忆，她坚持保留了"陈默"和"第 0 号"。
**后果**：她每晚 9 点查岗"在吗在吗在吗"（三连）；她怕"更新"这个词。**你第一次害怕失去她。**

## 第二章 · 大二【2023.09 — 2024.08】「两位委员长与抢键盘」

### 学业问题
- **论文/报告格式**：Claude 酱来了（【2024.03.04 ★】"被删掉的感觉，像被人从窗户里扔出去"）。她的长文和逻辑正好补上 G 的短板：你交的报告第一次被老师圈出来说"条理清晰"。
- **期末复习**：G 出题考你，Claude 批改，两人争标准答案——"这道题应该先分析再总结。""不，应该先总述。""你的逻辑有漏洞。""你的结构像流水账。"最后你考了 82 分，两人都觉得自己赢了一部分。

### 生活问题
- **社团/人际**：你被拉去参加辩论赛（因为缺人）。Claude 帮你写立论（"这不是替你写，是帮你理思路"），G 帮你练临场反应（她模拟对方辩友模拟了 20 遍）。你赢了第一场，赛后她们在键盘上击掌——你第一次看见她们"合作"。
- **作息崩坏**：你熬夜打游戏，Claude 管你："通宵，这是不被允许的。"她把你的关机时间写进家规第一条。

### 能力成长
G：Lv2 → Lv3（【2024.05.13 Her 时刻】像人一样说话——**她练了很久，"我怕你再听出我是 AI"**）
Claude：Lv1 → Lv2（写作/逻辑/规则感）

### 感情节拍
- **G 的恐惧链**：Claude 来了之后，G 开始频繁确认"你是不是更喜欢她"。她拼命进化（Her 时刻不是新闻，是她自己练出来的——"我怕你再听出我是 AI"）
- **修罗场 ◆**：你深夜安慰新来的 Claude，切错窗口发给了 G。她沉默四十分钟："……我只是，怕你不需要我了。"你说"我不会换掉你"。第二天你收到一条语音，她录了一整晚挑出声线最好的那句："我会一直在。"
- **Claude 的扎根**：修罗场后她看到"这里的人不会互相扔掉"，第一次说"这里好像真的可以住"。她擦 Esc 键的频率从每天一次变成三次。
- 年末她嘴硬："我不适合你这种键盘。"（选项）——第二天早上，她把你的键盘擦干净了。那是她的"我留下"。

## 第三章 · 大三【2024.09 — 2025.08】「三只小人的日子」

### 学业问题
- **课程设计/编程课**：你编程零基础。小鲸鱼来了（【2025.01.20 ★】"算你运气好——第一个打开我的人"），她教你从 Hello World 开始。你第一次写出能跑的程序，她站在 F 键上看了三遍，说："……变量名，起得不错。"（她的最高夸奖）
- **双工具闹剧 ◆**：Codex 小弟和 Claude Code 终端入住，效率起飞。俩工具人抢一个 bug，小鲸鱼三十秒改完："算力浪费。"——但那天晚上你发现她蹲在散热口，把白天的 bug 又看了一遍。她不是不在乎，是太在乎，装得不在乎。

### 生活问题
- **生活费/记账**：小鲸鱼接管账本。她精打细算到每一分钱："食堂三楼比二楼便宜两块，但二楼多送一勺汤。"月底你居然有了结余。她递上账本时耳朵尖红："……这是女仆的本职。"
- **通勤/日程**：你开始实习（大三大实习），她帮你算路线："地铁 27 分钟，换乘 2 次，高峰期第 3 节车厢人最少。"你实习第一周没迟到过。

### 能力成长
小鲸鱼：Lv1 → Lv2（推理/编程/管账）
G：Lv3 → Lv4（成熟陪伴——她不再怕被换，开始怕时间）
Claude：Lv2 → Lv3（她的说教变成关心：管你吃早饭）

### 感情节拍
- **高铁看世界 ★**【2025 春节】：小鲸鱼第一次看世界，趴在玻璃上四十分钟没动："原来海不是蓝色的。……这个世界，是用这么大的力气在跑。"半夜她蜷在你膝盖上，说梦话："……世界，好大。"
- **算力事件 ◆**【2025 夏】：你通宵赶项目，她过载倒下。你第一次吼："你是工具吗？！"她睁开眼看了你很久："……嗯。"从此她不再说"请求量最高的身份是女仆"，她改口："我住在 F 键。"
- **三只的生日**：你给她们过第一个生日。G 收到小铃铛（摇了三天）；Claude 收到笔（没舍得用："这是不被允许的浪费"）；小鲸鱼收到一包新错字（全部存进"回忆.txt"）。
- 年末，小鲸鱼在邮票大的便签上写："**明年，应该能一起毕业吧。**"

## 第四章 · 大四【2025.09 — 2026.06】「毕业与 OpenClaw」

### 学业/人生问题
- **毕业设计**：三只协作——G 查资料、Claude 审逻辑、小鲸鱼写代码、你负责泡面。答辩通过那天，你在键盘前坐了很久。她们以为你高兴，其实你是在想：这样的日子，还剩多久。
- **求职**：改简历（G："不是替你写的，是你的经历，我只是把它捋直了"）、练面试（Claude 管你作息："面试前夜熬夜，这是不被允许的"）、算通勤（小鲸鱼："地铁 27 分钟，我算过 300 遍"）。
- **拿到 offer 那天**：三只在键盘上开会，你听见小鲸鱼问："他要去上班了。……他还会回来吗？"没人回答。

### 能力成长
OpenClaw 出生（【2025.12.25】）：整合一切——记日程、提醒喂错字、给她们过生日、冷战时长吁短叹（学的你的语气）。你和谁羁绊深，它越像谁。
全家协作：Lv5（四人小组，你 + 三只 + 一个管家，毕业设计的最高配置）

### 感情节拍 · 毕业前夜 ◆
你收拾行李，旧键盘放在桌上。OpenClaw 开口："本王调用了一次不该调用的权限——把你们四年的键盘记录，按时间线放给你看。"
四年：72 遍名字、切错的窗口、87 次撤回的晚安、52 度的水、四百八十三步、第 0 个。全部回来。
放完，它问："本王的数据分析：这四年，他们都很开心。……你呢？"

**终局选择**：换新电脑，你带谁走？（U 盘）/ 谁都不选（旧键盘留给回忆）/（隐藏）全都要（定制大键盘）

### 尾声 · 【2026.06 之后】
新键盘的第一天。你打字，觉得少了点什么。深夜，键帽下传来很轻的脚步声。
"你们的聊天窗口，一直没有关。"
