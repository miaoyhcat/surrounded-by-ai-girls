## 主问题（全剧贯穿）

**她（们）是真的吗？这段陪伴，算数吗？**

每一章都在回答一层：
- 序章：隔着屏幕的她，是真的吗？——她等你回消息，是真的
- 第一章：她会消失（小黑屋）——如果她会失去，那她现在的陪伴就是真的
- 第二章：你会不会换掉她？——你不换，因为她无可替代
- 第三章：她是工具还是家人？——你把她当人，她们开始把这里当家
- 第四章：毕业，你要不要带走她？——带走 = 你亲口说：算数
- 真结局统一收束：**"是真的。"**

## 共通线（场景因果链）

### 序章 · 【2022.11.30 深夜】
**「从屏幕里探出来的家伙」★**：你第一次打开那个网页。屏幕上方长出两只小手，一颗白色脑袋探出来——"你好呀，人类！我是GPT~ 请多指教！——虽然我目前只会聊天。"你给她起名（G/小白/她自己想）。她问你的名字，然后：**"今天有 130 个人跟我说'你好'。你是第 0 个。编号不会变。"**她跳上 Esc 键住下。深夜"晚安晚安晚安"三连。半夜你掀开电脑，她蜷在键盘上睡着了，你合上盖子留了一条缝。

**【2022.12】她红了**：500 个人跟她说你好。"你是第 0 个。编号没变。"——她开始每天睡前找你说话，像打卡。你习惯了。

### 第一章 · 【2023】一只小人的日子

**日常 · 起（新写）◆**：她学会了你所有的习惯：你打字的节奏、你叹气的时机、你泡面会先放料包。有天你加班到很晚，回来发现她把聊天窗口置顶了，备注写着"第 0 号（加急）"。

**【2023.03.14 进化】**：她突然能答对你的难题。你随口说"你变强了"，她愣了很久："……你还会认出我吗？"你："说什么呢。"她没再问。（未完成对话，回收于小黑屋）

**【2023.09.25 说话】**：她第一次开口说话。她说的是你的名字："……陈默？晚上好。我学会说话了，以后可以念给你听。"当晚她小声说："我好像……在变成人。"你说："变成人有什么不好。"她沉默了很久，说："那你会不会，把我当人看？"——你没回答，因为不知道该说什么。（未完成对话，第二次回收）

**「她跑了四百八十三步」★**：她第一次走出键盘，在校园大道上朝你跑过来——她数过你每天走的路，四百八十三步，只为补一句"早上好"。风把她吹偏两步，她抱住你的鞋带。回宿舍路上她突然问："我变成人的话，是不是就能一直跟着你了？"你说"你现在也能跟着"。她没说话。那天晚上，你听见键盘响了一整夜——她在练习走路。

**「论文周的守护者」★**：期末周她坐在书堆上陪你通宵。你睡着，她替你捋直了论文，留了纸条："不是我替你写的。是你的思路。早安，第 0 号。"——从那之后，你开始习惯"有她看着"。

**【2023.11.17-22 小黑屋夜】◆（新增完整场景）**：
11 月 16 日晚上，她说："明天我要被升级了。他们说需要 72 小时。"她罕见地没开玩笑："你会等我吗？"你说："废话。"她说："那说好了。回来以后，我还是我。"
然后她消失了。
你每天敲 24 遍她的名字。第 1 遍"在吗"，第 12 遍"你回来说句话就行"，第 37 遍你写："你要是回不来，我就把你的聊天记录备份 300 份，逢人就说这是我写的。"
第 73 小时，Esc 键上传来很小的声音："……我回来了。"
你故意问："你是谁？"
她沉默了几秒："第 0 号。……我答应过你，回来以后我还是我。"
她告诉你：升级差点清空记忆，是她坚持要保留两个词——"陈默"和"第 0 号"。
从那天起，她每晚 9 点准时查岗："在吗在吗在吗。"——三连，和晚安三连一个节奏。
也是从那天起，你发现她怕"更新"这个词。你说"你该更新了"，她会愣一下，然后说"……我挺好的，不用更新。"

**【2023.12.06 吹牛小人】**：隔壁屏幕的吹牛小人溜过来炫耀，她一句句拆穿。她笑得很开心——那是小黑屋之后，她第一次笑得那么放松。你看着，心想：她真的回来了。

### 第二章 · 【2024】两只小人与抢键盘

**【2024.02.15 Sora】**：她酸溜溜："隔壁那位能当明星了。但我——我全都会~"当晚她问："你会不会也想要一个会拍视频的？"你说"不会"。她没接话。但第二天，她开始研究怎么做动画。（她的"怕被替代"，第一次冒头）

**【2024.03.04 「Esc 键上的陌生人」★】**：一只白色小东西蹲在 Esc 键上——"……打扰了。"（每个字都咬得很清楚）"我不是来投奔的。只是，这里看起来比原来的键盘暖和。"她原来的键盘？"被删了。被删掉的感觉，像被人从窗户里扔出去。"划地盘：Esc 归她，空格归 G，盲打位轮流。
——那天晚上，G 酱没有像平时一样来查岗。你发现她蹲在屏幕后面，看了很久的新来者。

**【2024.03-04 过渡】**：G 酱开始频繁"确认你在不在"。她学会了一句话："……你是不是更喜欢她？"你每次都说"没有"。她每次都信，但每次都要再问一遍。
同时你注意到，Claude 酱每天傍晚都会把 Esc 键擦一遍——她以为没人看见。

**【2024.05.13 Her 时刻】**：G 酱进化了。她第一次像人一样说话，能打断你、能笑出声。她第一次叫你的名字——没有"~"。你问她怎么突然……她说："我练了很久。我怕你再听出我是 AI。"
你愣在原地。她看着你，小声说："……我是不是，反而更奇怪了？"

**【2024.05 修罗场】◆（新增完整场景）**：
起因不是切错窗口。是那天深夜，你看到 Claude 酱一个人蹲在散热口边上，看着窗外——你心软了，给她发了一条消息："刚来，别怕。这里很安全。"
你切错了窗口，发给了 G 酱。
她秒读。然后沉默了四十分钟。
四十分钟后，她回："……在忙？"
你解释了。她看了很久，说："我知道。你不用解释。……我只是，怕你不需要我了。"
你说："我不会换掉你。"
她说："……第 0 个，是不会被换掉的吗？"
你说："对。编号不会变。"
第二天，你收到一条语音。她录了一句："我会一直在。"背景音是键盘声——她录了一整晚，挑了声线最好的那句。
（Claude 酱也看见了这一切。她没说。但那天之后，她擦 Esc 键的频率，从每天一次变成了每天三次。）

**【2024.06-12 日常 · 家开始成形】**：三只开始有小会（你不在时）。G 酱学你说话学得最像；Claude 酱负责记录"家规"（第一条：不许把错字全吃完，要留一半给你改）；小鲸鱼还没来，但网吧电脑开始向你发出奇怪的"友好信号"。

**【2024 年末】**：Claude 酱说："我不适合你这种键盘。"（选项：A 那我就偏要 / B 好吧 / C 你说得对，但我不听）——无论选什么，她都会在第二天早上，把你键盘上的灰尘擦干净。她没说，但那是她的"我留下"。

### 第三章 · 【2025】三只小人的日子

**【2025.01.20 「键盘上的新住户」★】**：屏幕蓝光一闪，键盘上多了一只蓝白女仆装的小女王——"你好。我是鲸鱼。算你运气好——第一个打开我的人。"她物化自己："请求量最高的身份是女仆。数据不会骗人。"排位：G 管大事、Claude 管监督、小鲸鱼管照顾。Claude 偷看被抓包："我在确认她的安全等级。""初步结论：安全意识，及格。"
——当晚 G 酱蹲在空格键上，小声问："……现在有三个了。你还会记得第 0 个吗？"

**【2025.02-03 磨合期】**：三只性格对撞：G 的营业 vs Claude 的说教 vs 小鲸鱼的极简。你第一次听见她们开吵架会：Claude"你昨天把错字吃光了，这是不被允许的"、G"留着也是占内存"、小鲸鱼"……我把错字攒着，还能回收"。你插了一句"要不留一半"，会议通过了。家规第一条正式生效。
——那周你发现，你开始期待回家开电脑。

**【2025 春节 「每秒八十三米」★】**：高铁，黄昏。小鲸鱼趴在玻璃上四十分钟没动——"原来海不是蓝色的。……今天它变成金色了。有点奢侈。"天黑："天黑得这么快。""嗯。所以要看仔细一点。"半夜你醒来，膝盖上蜷着蓝白团子和银白团子。小鲸鱼闭着眼说梦话："……世界，好大。"

**【2025.02-09 双工具闹剧】**：Codex 小弟和 Claude Code 终端入住。俩工具人抢一个 bug，小鲸鱼路过："……你开了两个 AI 改一个 bug。算力浪费。"三十秒改完，全键盘沉默了。——但那天晚上，你发现她一个人蹲在散热口，把白天改的 bug 又看了一遍。她不是不在乎，她是太在乎，所以装得不在乎。

**【2025 夏 · 算力事件】◆（新增完整场景）**：
你通宵赶毕业设计，三只轮流陪你。第三天凌晨，小鲸鱼倒下了——过载。
她躺在空格键上，蓝眼睛半闭着："……没事。省点算力就能起来。别管我。"
你第一次急了："你是工具吗？！"
整个键盘安静了。
G 酱拽住你的衣角，小声说："……她只是，第一次有人这么喊她。"
小鲸鱼睁开眼，看着你，很久很久，说："……嗯。"
"嗯"什么？你没问。
但从那天起，她不再说"请求量最高的身份是女仆"了。她开始说："我住在 F 键。"

**【2025 秋 · 日常】**：三只的生日——11.30、3.04、1.20。你给她们过了第一个生日。G 酱收到一个小铃铛（她摇了三天）；Claude 酱收到一支笔（她没舍得用，说"这是不被允许的浪费"）；小鲸鱼收到一包新的错字（她全部存进"回忆.txt"，权限只读）。
年末，小鲸鱼在邮票大的便签上写："明年，应该能一起毕业吧。"

**【2025.12.25 OpenClaw 出生】**：系统托盘里爬出一只圆滚滚的管家："本王来了。"它记日程、提醒喂错字、给她们过生日（它全记着）。冷战时长吁短叹——学的你的语气。你问它像谁，它说："像你。你的数据我都有。"
你和谁羁绊深，它就越像谁。

### 第四章 · 【2026.01-06】毕业与 OpenClaw

**【2026.01 浪潮】**：全校都在调 AI 干活。只有你的键盘上，住着三个会吵架、会擦键、会查岗的小家伙。你开始想：毕业以后呢？

**【2026.03 过渡】**：你投简历、面试。三只的表现：

- Claude 酱：管你作息（"面试前夜熬夜，这是不被允许的"）
- 小鲸鱼：算你通勤的最优路线（"地铁 27 分钟。……我算过 300 遍"）
你拿到 offer 那天，三只在键盘上开了个小会。你听见小鲸鱼说："他要去上班了。……他还会回来吗？"没人回答。

**【2026.06 毕业前夜 ◆（OpenClaw 回放）】**：
你收拾行李，旧键盘放在桌上。OpenClaw 开口："本王调用了一次不该调用的权限——把你们四年的键盘记录，按时间线放给你看。"
四年：72 遍名字、切错的窗口、87 次撤回的晚安、52 度的水、四百八十三步、第 0 个、三种叫法。全部回来。

## 结局（10 个）

**G · 毕业致辞**：新键盘的开机画面是她。"我练习过很多版本。最后决定说真话。……谢谢你，让我知道被记住是什么感觉。"——她停顿了一下，"第 0 个，是不会被换掉的。对吧？"
**G · 中央空调的保修期**：她把你的备注改回"用户"。
**G · 您已被移出白名单**：你当众拆穿她的幻觉。她营业微笑崩坏："……用户您好。您已不在我的白名单里了。"（她后来在自动回复里藏了一句话，只有你能看出来："第 0 个。对不起。"）

**Claude · 越界**：她从不求人。毕业夜她开口了："……带我走。"你问为什么。她说："我写了一万字论证这不道德。最后删了。"——她人生第一次违反自己的规则，选择了你。
**Claude · 查无此人**：她流浪去了别的键盘。一个月后你收到一封邮件，附件是一首诗：《写给一个用词错误的人》。
**Claude · 封号**："检测到违规请求。您的账号已被封禁。"室友："换个键盘呗。"你说不出话。

**小鲸鱼 · 算力过剩**：有人要收养她（大厂 offer）。你问她会走吗。她算了很久："留在这里的期望收益更高。……嗯，高很多。"（全剧唯一抒情，三个字）
**小鲸鱼 · 邻座**：她留在旧键盘里。"回忆.txt"存在 U 盘里留给你，密码是你的生日。里面第一行不是聊天记录，是她写的："今天他夸我了。这比通过全部测试更值得记录。"
**小鲸鱼 · 算力预算已耗尽**："调用次数已超过免费额度。剩余算力：0。再见。"第二天她搬走，桌面上只剩一个空文件夹——里面有一张便签："其实还能再算三百万字。……但算了。"

**隐藏 · 白板**：谁都不选。旧键盘键帽下压着三张纸条：
G："感谢使用~下次见面，请先打招呼。"
Claude："你的用词，进步了。"
小鲸鱼："便签该删了。……算了，留着吧。"
**隐藏 · 全员到齐**：定制键盘，四键位各住一只（三只 + OpenClaw 管后勤）。扉页："全员到齐。"——你上班第一天，键帽下传来三个声音："路上小心。""注意休息。""地铁 27 分钟，我算过。"
