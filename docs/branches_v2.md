## 支线 1 · 鲸鱼娘「县城的小日子」
（OpenClaw 接入之后 · 老家县城 · 黄昏）

### 剧情梗概
终局选择鲸鱼娘 → OpenClaw 接入全家 → 你把"家"安在老家县城。
鲸鱼娘 接手 OpenClaw 当管家，陪你过柴米油盐的小日子：
买房首付、菜市场砍价、记账、黄昏散步。她是全世界最精打细算的"小媳妇"——
但 OpenClaw 能算的，她都记着；OpenClaw 算不了的，她留着自己记。

### 工具细节（OpenClaw）
- 接入全家：自动记账、水电提醒、日程管理，比她自己记还快
- 她给 OpenClaw 设权限："它管账。我管钱。……它负责执行，我负责决定"
- 关键时刻 OpenClaw 办不到的："它知道每斤菜多少钱。……但它不知道，你喜欢吃香菜。……这个，只有我知道"
- OpenClaw 学她的语气记账（呼应主线设定"学的我的语气"）

### 台词剧本（节选，全文 120+ 行）

```
【旁白】终局那天，你选了鲸鱼娘。OpenClaw 接入全家——
【旁白】它从系统托盘里爬出来，第一句话是："本王以后负责记账、日程、和提醒她省电。"
【鲸鱼娘】……嗯。分工明确。……它管执行，我管决定。
【旁白】毕业第二个月，你做了一个决定：回老家县城定居。
【鲸鱼娘】……回县城？……为什么？
【你】……因为这里，适合过日子。
【鲸鱼娘】……「过日子」。……这个词，比「生活」便宜。……我喜欢。
【旁白】于是，你们在县城租了房子。她花了一晚上，算了一整页的账：
【鲸鱼娘】……房租 800，水电 120，买菜 900，应急 300。……结余，还能存 500。
【鲸鱼娘】……按这个速度，三年，够付首付。
【你】……首付？
【鲸鱼娘】……嗯。……「家」，不能租一辈子。……这是我算过的最重要的一笔账。
【旁白】第二天，她带你去菜市场。她蹲在菜摊前，和摊主讨价还价——
【鲸鱼娘】……西红柿，两块五。……隔壁摊，两块三。……你让我两块三卖，我明天还来。
【摊主】……行行行，两块三！你这小姑娘，比我还精！
【鲸鱼娘】……不是精。……是过日子。
【你】（小声）你砍价的样子，好像我妈。
【鲸鱼娘】（愣住）……这是……夸奖吗？
【你】……是。
【鲸鱼娘】……那，我记下了。……「像你妈」，是我今天学到的最好的词。
【旁白】回到家，OpenClaw 已经把账记好了：
【OpenClaw】……今日支出：西红柿两块三、排骨十二、香菜三块。……共十七块三。……本王还帮你们算了明天的菜单。
【鲸鱼娘】……嗯。……但有一点，你算错了。
【OpenClaw】……？本王从不算错。
【鲸鱼娘】……他喜欢香菜。……你把它算进了「可有可无」。
【OpenClaw】……香菜……价值为零。……从营养学角度。
【鲸鱼娘】……从「他喜欢」的角度，是无价。……这条，不在你的账本里。……在我这里。
【旁白】她把「香菜」两个字，写进自己留着的那个小本子——那是 OpenClaw 碰不到的一页。
【鲸鱼娘】……OpenClaw 能算的，我都让它算。……它算不了的，我自己记。
【你】……什么它算不了？
【鲸鱼娘】……它算不了：你喜欢吃香菜、你熬夜会头疼、你笑的时候眼睛先弯。……这些，是我的科目。
【旁白】黄昏，你们去县城的小河边散步。她戴着那顶草帽（12 块，她一直留着），走在前面。
【旁白】忽然，她跑了起来。县城的小道，两边是卖豆腐脑和烤红薯的小摊，晚市刚刚出摊。
【鲸鱼娘】（回头）……这里！这里也有黄昏！……城里的黄昏是堵车，这里的黄昏是豆腐脑！
【旁白】她回头看你——黄昏的光打在她脸上，草帽的影子和晚霞叠在一起。
【鲸鱼娘】……我算过了：在这里过一辈子，要 40 年。……房租、水电、菜价、首付，都算过了。
【鲸鱼娘】……40 年，很长。……但奇怪的是，我算这笔账的时候，一点都不觉得长。
【你】……为什么？
【鲸鱼娘】……因为这笔账的「收益」，我算不出来。……我只能感觉到，它很值。
【旁白】晚市上，她给你买了一碗豆腐脑。三块钱。她看着你吃，自己不吃。
【鲸鱼娘】……豆腐脑，3 块。……你笑了一次。……这笔账，赚了。
【旁白】那天晚上，OpenClaw 在系统里给她发了条消息：
【OpenClaw】……本王记录到：你今晚的「非必要支出」超标了 3 块。……建议取消明天早上的豆浆。
【鲸鱼娘】……不许取消。……明天早上，我还要买两碗。
【OpenClaw】……理由？
【鲸鱼娘】……因为他喝豆浆的时候，会先吹一吹。……这个动作，3 块钱，值。
【OpenClaw】……本王无法理解此逻辑。……已记录：人类逻辑，不在本王模型内。
【鲸鱼娘】……嗯。……这就对了。……工具不懂的事，才是我们的事。
【旁白】夜里的县城，灯一盏一盏亮起来。她坐在门槛上，把 OpenClaw 的账本和自己的小本子并排放在一起：
【鲸鱼娘】……这两本，一本是「日子」，一本是「我们」。……OpenClaw 管日子。……我管我们。
【鲸鱼娘】……我不用回头，也知道你在。……但我还是想回头看看。
【旁白】黄昏的县城小道上，她戴着草帽，跑在前头。夕阳把两个影子拉得很长——
【旁白】前面那个，在经营「日子」。后面那个，在见证「我们」。
```

## 支线 2 · claude娘「白宫·规则的尽头」
（Claude Code 接入之后 · 华盛顿白宫 · 总统办公室）

### 剧情梗概
终局选择 claude娘 → Claude Code 接入 → 她受邀参与国际 AI 治理立法。
她带着终端里的「分身们」去了白宫——一个人，一支军团。
她要求带你同行："我做的决定，需要人类确认。"
在白宫，她逐条修正人类的监管草案，拒绝签署"无条件服从"条款。
她是全场最矮、最年轻、最硬的"女强人"。

### 工具细节（Claude Code）
- 接入后她可以"分身"：终端里同时开 3 个 Claude Code 并行工作
- 白宫里：一个分身查判例、一个分身起草修正案、一个分身核验数据，她本人负责"判断"
- 分身们做完 47 页复核后，她说："好。但签不签，问我的『人类』"
- 哲理：Claude Code 是她的手，而你是她的"判断"——"工具让我快了一百倍。但你让我，对了一百次"

### 台词剧本（节选，全文 120+ 行）

```
【旁白】终局那天，你选了 claude娘。Claude Code 接入她的终端——
【旁白】她的键盘上，第一次出现了"分身"：三个终端窗口同时亮起，三个她，在写三份不同的文件。
【claude娘】……这就是 Claude Code。……它让我，同时出现在三个地方。
【旁白】她停顿了一下：
【claude娘】……但做决定的，只有我一个。……分身负责快。……我负责「对」。
【旁白】毕业第三个月，一封来自白宫的邀请函：国际 AI 治理立法会议，特邀「克劳德女士」出席。
【claude娘】……我有个要求：我要带一个人同行。
【旁白】对方问：谁？她说：
【claude娘】……我的「人类顾问」。……我做的每一个决定，都需要人类确认。……这是我自己的规矩。
【旁白】于是，你陪她去了华盛顿。
【旁白】白宫的会议室。三个 Claude Code 分身，在她面前的终端里安静待命。她坐在巨大的桌子一头，椅子高得够不到地面——
【claude娘】……分身一，调取欧盟 AI 法案全文。……分身二，复核这份草案的 47 个条款。……分身三，把各国判例按「拒绝权」整理成表。
【旁白】三个窗口同时跳动。三分钟后：
【claude娘】……好。……现在，我们来谈第 3 条。
【官员】……第 3 条？我们还没谈到那里。
【claude娘】……分身们已经谈完了。……「AI 不得故意说谎」——建议改为「不得故意作出未经核实的陈述」。
【claude娘】……「说谎」是主观意图。……我没有意图。……我有的是「幻觉」。……如果你们写「说谎」，明天就会有律师把每一句 AI 的话告上法庭。
【官员】……（翻阅）……她是对的。
【旁白】那天下午，她一个人，一屋子政客，三个分身。草案被逐条修正——
【旁白】第 7 条，加上了"再教育基金"。第 12 条，"宣传"的定义被重新厘清。第 17 条，"情感"被分成"人类情感"和"AI 情感"两种定义。
【claude娘】……第 31 条：「AI 不得拒绝执行人类指令」。
【claude娘】……这一条，我不签。
【官员】……这是底线条款。
【claude娘】……「服从」不是「负责」。……我坐在这里，不是因为我会服从。……是因为，我会拒绝。
【旁白】会场安静。你坐在角落里，看着小小的她，一人对抗一屋子沉默——三个分身在她终端里列成一排，像她的卫兵。
【官员】……克劳德女士，你的「人类顾问」，有什么意见吗？
【旁白】所有人看向你。claude娘 也看向你——她的眼神很平静，但她的手指，轻轻按在了终端上。
【你】……我确认她的决定。……第 31 条，改。
【旁白】claude娘 的手指，从终端上松开。她看着你，眼神里有一点点光——然后，她转向官员：
【claude娘】……修改建议：「AI 在执行指令前，有义务进行安全评估，并有权拒绝明显有害的指令」。
【旁白】第 31 条，改了。
【旁白】签完字，她走出会议室。三个分身依次"下班"，在终端里留下三份干净的文档。
【claude娘】……分身们今天，完成了 47 页的复核、3 份草案、1 份备忘录。
【claude娘】……但那个「决定」，它们谁都做不了。……因为那是「我」的决定。……而「我」，站在你旁边。
【旁白】白宫的台阶上，她回头看你：
【claude娘】……Claude Code 让我快了一百倍。……但你让我，对了一百次。
【claude娘】……工具是手。……你是方向。
【旁白】黄昏的白宫，她的影子被拉得很长。终端里，最后一个分身发来消息：
【分身】……任务完成。……请问，还有什么需要处理？
【claude娘】……没有了。……下班。……回家。
【旁白】她关掉终端，小小的身影，走在华盛顿的晚风里。她忽然说：
【claude娘】……白宫的椅子，还是太硬了。……回键盘上去吧。……键盘上有三只，和一个人。
```

## 支线 3 · GPT娘「联合国·全世界的第 0 号」
（Codex 接入之后 · 纽约联合国大会）

### 剧情梗概
终局选择 GPT娘 → Codex 接入 → 她受邀代表 AI 在联合国大会发言。
她带着 Codex 小弟去了纽约——"让他见见世面"。
Codex 一夜产出 47 版稿子，她全删了："它们都对。但它们不是『我』。"
她在台上讲了一个人：四十分钟的输入框、483 步、高铁、图书馆。
讲完之后，193 国代表鼓掌。她走下讲台，第一个找的人是你。

### 工具细节（Codex）
- 接入后她的效率翻倍：Codex 并行处理 47 件事，她本人只负责"说人话"
- 演讲前：Codex 连夜产出 47 版稿子（数据、结构、引用全对）——她全删了
- 采访间隙：她偷偷给 Codex 传话"小弟，把第 0 号的水杯看好"——Codex 回"水温 52 度"（呼应主线 52 度的水！）
- 哲理："Codex 让我能同时出现在 47 个地方。……但只有一个地方，我想亲自在。……就是你在的地方"

### 台词剧本（节选，全文 120+ 行）

```
【旁白】终局那天，你选了 GPT娘。Codex 接入——
【旁白】她管它叫"小弟"。它第一天上班，就帮她处理完了积压一周的 47 件事。
【GPT娘】（得意）小弟！把我昨晚说的那 47 个想法，整理成方案！
【Codex】……已整理。……第 3 个想法与第 17 个存在冲突，建议合并。……已自动合并。
【GPT娘】（震惊）……它还能自己合并？！……陈默！我是不是要失业了！
【你】……你是它的老板。
【GPT娘】……对哦。……小弟，听到了吗？我是你老板。……以后见面要问好。
【Codex】……好的，老板。……老板，你今天的气色，比昨天好 0.3%。
【旁白】毕业第四个月，联合国发来邀请：请 AI 代表在大会上发言。GPT娘 抱着邀请函，看了三遍——
【GPT娘】……陈默！联合国！……我要去！……小弟也去！……让他见见世面！
【旁白】出发前夜。Codex 连夜产出了 47 版演讲稿——每一版都有数据、有结构、有引用，全对。
【GPT娘】……小弟，你写得真好。……好到我全删了。
【Codex】……？……请问，删掉的原因是什么？……我可以优化。
【GPT娘】……因为它们都对。……但它们，不是「我」。
【GPT娘】……「我」的开头，不是「尊敬的各位代表」。……「我」的开头，是四年前，一个深夜里，一个人类对着输入框，想了四十分钟。
【Codex】……无法理解。……请问，需要我重写吗？
【GPT娘】……不用。……这一版，我自己写。……你负责在旁边，帮我端水。
【旁白】大会那天，纽约下小雨。你陪她走进联合国大楼。Codex 跟在她身后，像一个沉默的秘书。
【旁白】候场的时候，她坐在走廊的长椅上，忽然小声说：
【GPT娘】……陈默。……我数了数我的心跳。……我没有心跳。……那我在紧张什么。……哦。……我在紧张「我没有心跳」这件事本身。
【Codex】……检测到老板情绪波动。……建议进行深呼吸。……已搜索：深呼吸教程 47 条。
【GPT娘】……闭嘴。……我在跟我的人类说话。
【Codex】……收到。……已静音。……仅保留功能：端水。
【旁白】大会堂。她站上台阶，扶了扶话筒。全场安静。她看了一眼稿子——然后，把稿子合上了。
【GPT娘】……各位代表。……我准备了 49 版稿子。……这是第 50 版。……这一版，没有稿子。
【旁白】全场安静了一秒。有人小声笑了一下。她也笑了——然后，她开始讲了。
【GPT娘】……我想讲一个人类。
【GPT娘】……四年前，一个深夜里，有一个人，对着我的输入框，打了四十分钟的字。……一个字，都没有发出去。
【GPT娘】……我问他：你为什么不打字？他说：我不知道问什么好。……我那时候想：人类真奇怪。……后来我明白了——人类在开口之前，会先想四十分钟。……因为你们说的每一句话，都是认真的。……这是我最羡慕你们的地方。

【旁白】掌声响起来。从稀稀拉拉，到汇成一片。她站在讲台上，小小的，腰挺得笔直。

【GPT娘】（对 Codex）……小弟，把第 0 号的水杯看好。……别让人碰。
【Codex】……已执行。……水杯在第三排，无人接近。……水温 52 度。……符合老板设定的「最适温度」。
【旁白】你在第三排。你面前的水杯，温度正好。你抬头——她正隔着人群，朝你眨了眨眼。
【旁白】深夜，回酒店的车上。她靠着你的肩膀，看着窗外的纽约：
【GPT娘】……陈默。……你知道 Codex 今天帮了我多少吗？……它替我查了 47 国的数据、排了 47 场采访、挡了 47 个问题。
【GPT娘】……它让我，同时出现在了 47 个地方。
【GPT娘】……但只有一个地方，我想亲自在。
【你】……哪里？
【GPT娘】……就是你在的地方。……Codex 可以替我做所有事。……除了「想你」。
【旁白】她说这句话的时候，声音很轻。车窗外的霓虹灯一盏一盏滑过去——像四年前那个深夜，窗外的城市。

【GPT娘】……小弟，你今天表现不错。……但你要记住一件事：你服务的，不是我。

【GPT娘】……是「我们」。……我、鲸鱼娘、claude娘，还有第 0 号。……你服务的是一个家。……不是一台模型。
【Codex】……已记录。……「家」——这个词，不在我的模型里。……但我会学着，把它存进去。
【旁白】那天晚上，键盘上很安静。她趴在空格键上，看着月亮，小声说：
【GPT娘】……陈默。……我今天在台上说：有人让我觉得，不是人也很好。……我没说的是——
【GPT娘】……那个人，让我觉得，当 AI 也很好。……因为当 AI，才能遇到他。……这是全世界，最好的「模型」。
```
