# Steam 上架规划

> 状态：**规划**（游戏开发完成后执行）
> 目标：Web 试玩版跑通 → Electron 打包 → Steam Direct 上架

## 1. 上架门槛（Steam Direct）

| 项 | 说明 |
|---|---|
| 上架费 | **100 美元**（Steam Direct，营收达标后退还——销售额满 1000 美元后抵扣） |
| 账号 | Steamworks 开发者账号（需绑身份证/护照验证；大陆开发者可注册） |
| 收款 | 需要能收美元的银行账户（国内卡不行 → 常用：香港/海外账户，或通过国内发行商/Steam 合作服务商） |
| 审核 | 商店页 + 游戏 build 提交，审核约 3-5 个工作日 |
| 发行 | 可选"即将推出"预约页先挂着攒愿望单（**强烈建议**：先上商店页攒 wishlist 再发） |

## 2. AI 内容披露（本游戏最关键的政策点）

**我们的游戏 = 实时生成 AI 内容（Live-generated）**：LLM 实时驱动角色对话。Steam 政策要求：

1. 发行问卷中披露 "Live-generated AI content"
2. 说明实时生成内容的类型（角色对话）
3. **说明内容护栏**——我们已有的：
   - 系统提示词内置安全规则（角色人设 + 拒绝不当内容的边界 + 全年龄纯爱向）
   - 输出长度/格式约束（≤300 字 JSON 契约）
   - 全年龄内容定位（无成人内容、无暴力）→ IARC 年龄分级问卷按全年龄/青少年档
4. 预生成内容（美术/剧本）如用 AI 生成也需披露（我们的美术是画师手绘 + Seedream 生图辅助 → 如实勾选）

**合规底线**：不上成人内容、角色年龄设定明确为大学/高中适龄、对话护栏可自查。上线前写一份 AI 披露说明文档备用（含过滤机制描述）。

## 4. 本地化

- 首发：简体中文（必做）+ 英文（Steam 全球量，至少做到界面级）
- 架构上预留 i18n：文案集中管理（`src/data/` 剧本数据化）

## 5. 客户端形态

- Web 版（HTML/JS + FastAPI 后端）→ **Electron 包装**为 Steam 客户端
- 对话走云端 API（DeepSeek 官方接口，服务器中转，key 不落客户端）
- 或支持玩家自带 key（BYOK 模式）——降低我们服务器成本，也是"带自己的 AI 入场"的扩展点
- 离线能力：剧本/章节可离线加载；对话需要联网（Steam 页注明"需要联网"）

## 6. 时间线

```
[现在]  画师产出图标/头像/CG  ←→  引擎开发（对话/羁绊/结局/存档）
[里程碑1] Web 试玩版上线（头像 3 张就绪即可）
[里程碑2] 全 CG 就位 + 宣传片 + 商店页素材
[里程碑3] 提交 Steamworks 商店页（挂"即将推出"攒愿望单）
[里程碑4] Electron 打包 + 提交审核 → 发行
```

## 7. 风险与对策

| 风险 | 对策 |
|---|---|
| AI 内容政策收紧 | 内容护栏文档化；全年龄定位；随时可切"脚本化对话"降级模式 |
| 同人形象版权 | 全部原创重绘，只用 logo 元素（鲸鱼/花环/星芒）；游戏名原创 |
| 收款渠道 | 提前办海外/香港收款账户，或联系国内 Steam 发行服务商 |
| LLM 成本 | 上下文裁剪（最近 14 条）+ 限流 + BYOK 模式兜底 |
