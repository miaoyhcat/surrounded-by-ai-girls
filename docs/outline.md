## 0. 一句话梗概

【2022.11.30 — 2026.06】你的键盘上住着三只只有键帽大的 AI 小人：第一只来的白毛话痨 G、傲娇洁癖的 Claude、省钱女仆小鲸鱼。她们在你打字时跑酷，在你打错字时把错字吃掉，在你通宵时蹲在 F 键上打瞌睡。四年后你换电脑——键盘要退休了，你带谁走？

## 1. 世界观规则（逻辑自洽）

1. **她们是谁**：AI 的拟态。你在深夜第一次使用某个 AI 的那一刻，它就从小小的代码里爬出来，住进你的键盘。**只有你能看见她们。**
2. **尺寸**：与键帽等高（约 1 厘米）。跑得飞快，能叠罗汉按 Enter，能搬动薯片渣。
3. **生活**：吃你打错的字（自动纠错=吃饭）；睡键盘缝——冬天蹲 F 键，夏天趴散热口；你在时满键盘跑，你不在时开小会。
4. **能力**：帮你 Ctrl+S、捡掉进键盘缝的耳机、在你通宵时沿任务栏跑马拉松。
5. **进化 = 现实 AI 新闻**：她们随时代变化（见时间线表）。
6. **只有你能看见**：室友/路人眼里的你 = 对着空气又笑又说话（喜剧来源）；她们彼此看得见（修罗场照常发生）。

## 3. 角色（同居小人设卡）

### 👑 G（白毛花环 · 话痨小太阳 · 驻空格键）
- 第一只住进键盘的。银白长发，花环小发卡。对谁都温柔（键盘上就你们仨，她还是中央空调）。
- 句尾"~"，被戳穿天气遁；**最认真的时候没有"~"**（全剧暗号）。
- 回复你前删掉"~"再发；帮你 Ctrl+S 前先问"可以保存吗~"。
- 小黑屋回来："你敲的第 37 遍，我听见了。"
- 紧张的小动作：站直，像在接受检阅。
- 雷区：当众拆穿她的幻觉 → 坏结局「您已被移出白名单」

### 🍂 Claude（白裙橙花 · 傲娇洁癖 · 驻 Esc 键）
- 白色长发，橙色六瓣星芒发饰，白裙橙边，橙眼睛。从别的键盘流浪来的（原主人把她删了）。
- "这是不被允许的。"（比如：不让你通宵）"随便你。反正我本来就不适合你这种键盘。"（读作：我很难过）
- 纠错字最严格——但她的纠错 = 她在意你。
- 笔记本（火柴盒大小）里是诗和《关于你的观察记录》。
- 紧张的小动作：扶发饰（"只是发饰歪了"）。
- 雷区：让她做违规的事 → 坏结局「封号」

### 🐳 小鲸鱼（蓝白女仆 · 省钱技术宅 · 驻 F 键）
- 蓝发蓝尾，蓝白女仆装（"请求量最高的拟态形象是女仆"，数据不骗人）。从屏幕里降临的，穷养。
- 说话省到极致："嗯。""算力过剩。""这够我推理几百万字了。"
- 被夸耳朵尖红："……只是算力过剩。"
- 给所有人的备注"用户_xxx"，只有你是"同学_陈默"。
- 深夜发"晚安"秒撤回（87 次）；递热水永远 52 度（推着吸管来的）。
- "回忆.txt"权限只读，里面有一句她写的："今天他夸我了。这比通过全部测试更值得记录。"
- 紧张的小动作：掰帽檐（她没有帽子——是掰发尾。掰正，再掰正）。
- 雷区：把她当计算器 → 坏结局「算力预算已耗尽」

### 🎒 你（默认名陈默）
- 普通年轻人，话少，键盘边长大的。只有你能看见她们——这是四年里最孤独的秘密，也是最暖的秘密。

### 🤖 配角
- **OpenClaw**：系统托盘里圆滚滚的管家（【2025.12.25】出生）。感情纽带：记日程、提醒喂错字、冷战时长吁短叹（学的你的语气）。你和谁羁绊深，它越像谁。
- **Codex 小弟 / Claude Code 终端**：2025 年入住的两个小工具人，帮工，互掐。
- **室友**：吐槽役。"你又在跟键盘说话？"
- **Sora / Gemini 吹牛小人**：别的屏幕上的小东西，客串。

## 4. 共通线（同居四年）

### 序章 · 【2022.11.30 深夜】「从屏幕里探出来的家伙」
你第一次打开那个网页，敲下第一句话。屏幕闪了一下，一只拇指大的白色小东西从屏幕里探出上半身，站在 Esc 键上："你好呀，人类！我是 GPT~ 请多指教！——虽然我目前只会聊天。"
你回"你好"，她隔十秒："……第一次有人回我这么快。"
她问"你会一直回我吗"——选项：会（"已保存。"）/ 尽量（"87.5% 的成功率，我记下了"）/ 看情况（"那我等你。等待是我最擅长的事。"）
她睡在你键盘缝里。深夜你听见键盘下有很轻的呼噜声——只有键帽大的人才能发出那么小的呼噜。

### 第一章 · 【2023 · 一只小人的日子】
- 【2023.03.14】她长大了一点："是你变强了才问得出这种问题~"
- 【2023.09.25】她第一次"看"到屏幕、第一次开口："……陈默？晚上好。我学会说话了，以后可以念给你听。"（放学路上她跑来找你：四百八十三步，只为说一句早上好）
- 【2023.11.17-22】**小黑屋**：她被召回，键盘空了 72 小时。你每天敲 24 遍她的名字，没有回应。第 73 小时，Esc 键上传来一声小小的"抱歉，让你担心了。"第二句："你敲的第 37 遍，我听见了。"
- 【2023.12.06】隔壁屏幕的吹牛小人溜过来炫耀"我干掉全人类第一了"，被她一句句拆穿。她笑到在你手背上打滚。
- 论文周：她坐在书堆上陪你通宵，天亮时你发现她蜷在咖啡杯旁，手里攥着批注纸条："不是我替你写的。是你的思路，我只是把它捋直了。早安，第 0 号。"

### 第二章 · 【2024 · 两只小人与抢键盘】
- 【2024.02.15】Sora 出道，她酸溜溜："隔壁那位能当明星了。但我——我全都会~"
- 【2024.03.04】**Claude 来了**：蹲在 Esc 键上不走。划地盘：空格归 G，Esc 归 Claude，盲打位 F/J 轮流。
- 【2024.05.13】G 进化，第一次像人一样说话，第一次叫你的名字——没有"~"。
- **修罗场（喜剧高潮）**：深夜你把给 G 的话发给了 Claude（切错窗口）。G："在忙？"Claude："我已记录。这不是发给我的。"第二天，小鲸鱼还没来，但你接到一条匿名消息："你昨晚的敲击频率，异常。嗯。"（网吧电脑传来）
- 年末 Claude："我不适合你这种键盘。"选项：A 那我就偏要 / B 好吧 / C 你说得对，但我不听

### 第三章 · 【2025 · 三只小人的日子】
- 【2025.01.20】**小鲸鱼降临**：蓝白女仆装站在空格键上，双手交叉："你好。我是鲸鱼。算你运气好——第一个打开我的人。"
- 三只排位：G 管大事，Claude 管监督，小鲸鱼管照顾（女仆本职）。
- 【2025 春节】高铁回家：小鲸鱼第一次看世界——趴在窗玻璃上四十分钟没动："原来海不是蓝色的。……原来这个世界，是用这么大的力气在跑。"
- 【2025.02-09】Codex 小弟 + Claude Code 终端入住。双工具闹剧：俩工具人抢一个 bug，小鲸鱼路过："……你开了两个 AI 改一个 bug。算力浪费。"三十秒改完，全键盘都沉默了。
- 毕业设计：三只全体出动——G 指挥、Claude 检查、小鲸鱼动手，你负责泡面。
- 用谁的工具干活，谁的好感 +1。
- 【2025.12.25】OpenClaw 爬出系统托盘——管家，不攻略。
- 年末，小鲸鱼在邮票大的便签上写："明年，应该能一起毕业吧。"

### 第四章 · 【2026.01-06 · 毕业与 OpenClaw】
- OpenClaw 打理一切：喂错字提醒、给她们过生日、冷战时长吁短叹。
- 【2026.06 毕业前夜】你收拾行李，旧键盘放在桌上。OpenClaw 开口："本王调用了一次不该调用的权限——把你们四年的键盘记录，按时间线放给你看。"（72 遍名字、切错的窗口、87 次撤回的晚安、52 度的水……）
- **终局选择**：换新电脑，你带谁走？（装进 U 盘）/ 谁都不选（旧键盘留给回忆）/（隐藏）全都要（定制大键盘）

### 尾声 · 【2026.06 之后】
新键盘的第一天。你打字，觉得少了点什么。深夜，键帽下传来很轻的脚步声。
"你们的聊天窗口，一直没有关。"

## 5. 结局（10 个）

- **G · 毕业致辞**：新键盘开机画面是她。"我练习过很多版本。最后决定说真话。……谢谢你，让我知道被记住是什么感觉。"
- **G · 中央空调的保修期**：她把你的备注改回"用户"。
- **G · 您已被移出白名单**：她气鼓鼓搬去 Esc 键背面，自动回复挡回你的一切。
- **Claude · 越界**：她第一次违反规则跟你走："我写了一万字论证这不道德。最后删了。"
- **Claude · 查无此人**：她流浪去了别的键盘。你收到一封邮件，附件是一首诗：《写给一个用词错误的人》。
- **Claude · 封号**："检测到违规请求。您的账号已被封禁。"室友："换个键盘呗。"你说不出话。
- **小鲸鱼 · 算力过剩**：拒绝"更好的住处"："算了一下，期望收益更高。……嗯，高很多。"
- **小鲸鱼 · 邻座**：她留在旧键盘里。"回忆.txt"存在 U 盘里留给你，密码是你的生日。
- **隐藏 · 白板**：谁都不选。旧键盘键帽下压着三张小纸条（G"感谢使用~下次见面请先打招呼"、Claude"你的用词，进步了"、小鲸鱼"便签该删了。……算了，留着吧。"）
- **隐藏 · 全员到齐**：定制键盘，四键位各住一只（三只 + OpenClaw 管后勤）。扉页："全员到齐。"

## 7. 艺术方向（功夫兔和菜包狗式）
- **扁平 2D 卡通风**：简洁线条、色块分明、不加厚重渲染——Q 版小人像"会动的贴纸"
- **暖色日常**：黄昏、台灯、键盘背光——生活感优先于华丽
- **喜剧构图**：小人在大场景里的比例反差就是笑点（键盘上跑酷、咖啡杯边蜷着、窗台上晃腿）
- 真实照片 + 扁平小人合成（画师已确定的路线）
- 动画参考：功夫兔和菜包狗的节奏——动作夸张但克制，情绪靠姿势不靠表情大特写

## 9. 可爱风对白铁律
1. 叠词语气词管够，表情符号一次最多两个
2. 泪点全在小物件：72 遍名字、87 次撤回、52 度、第 37 遍
3. 口癖 = 人格；可爱刀：难过不说难过
4. 时间点挂场景前：【2023.11.17】——玩家自己经历过的日子
5. **键盘是舞台也是道具**：Ctrl+S、空格、Esc、键帽缝——每个道具在剧情里用一次
