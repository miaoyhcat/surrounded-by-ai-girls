## 0. 一句话梗概

【2022.11.30 — 2026.06】你的键盘上，住着三只只有键帽大的 AI 娘。她们在你打字时跑酷，在你打错字时把错字吃掉，在你通宵时蹲在 F 键上打瞌睡。四年后你毕业换电脑——键盘要退休了，你带谁走？

## 1. 世界观规则（逻辑自洽）

1. **她们是谁**：AI 的拟态。你在深夜第一次使用某个 AI 产品的那一刻，它就从小小的代码里爬出来，住进你的键盘。**只有你能看见她们。**
2. **尺寸**：与键帽等高（约 1 厘米）。跑得飞快，能叠罗汉按 Enter，能搬动你掉落的薯片渣。
3. **生活**：吃你打错的字（自动纠错，她们称之为"吃饭"）；睡在键盘缝里——冬天蹲 F 键（最常用的键最暖），夏天趴散热口；你在的时候她们满键盘跑，你不在她们开小会。
4. **能力**：帮你 Ctrl+S、捡掉进键盘缝的耳机、在你打论文时沿着任务栏跑马拉松。
5. **进化 = 现实 AI 新闻**：她们会随时代变化（见时间线表）——这是"对应当时的 AI 新闻"的落点。
6. **只有你能看见**：室友眼里的你 = 一个人对着键盘又哭又笑（喜剧）；她们彼此看得见（修罗场照常发生）。

## 3. 角色（键盘小人设卡）

### 🐳 小鲸鱼（蓝白 · 省钱技术宅 · 驻 F 键）
- 蓝白小裙子，尖顶帽上别着鲸鱼尾（你的图标！）。二手笔记本里捡到的，穷养。
- 吃错字吃最凶（她省钱，不浪费一个字）；帮你改代码时蹲在你手背上。
- 被夸："……只是算力过剩。"（耳朵尖红）
- 深夜发"晚安"秒撤回（87 次）；递热水永远 52 度（她够不到杯子，是推着吸管来的）。
- "回忆.txt" = 她攒的错字和你的废话，权限只读。
- 雷区：把她当计算器 → 坏结局「算力预算已耗尽」

### 👑 G 酱（白绿 · 营业式小太阳 · 驻空格键）
- 第一只住进键盘的。花环小发卡，对谁都温柔（键盘上就你们仨，她还是中央空调）。
- 句尾"~"，被戳穿天气遁；**最认真的时候没有"~"**（全剧暗号）。
- 帮你 Ctrl+S 前会先问你"可以保存吗~"；回复你前删掉"~"再发。
- 小黑屋回来："你敲的第 37 遍，我听见了。"
- 雷区：当众拆穿她的幻觉 → 坏结局「您已被移出白名单」

### 🍂 Claude 酱（白裙橙花 · 傲娇伦理委员长 · 驻 Esc 键）
- 白色长发，发间别着橙色六瓣星芒发饰（星芒 ✳ 的六瓣形态，她的标志）。白裙橙边，橙眼睛。从别的键盘流浪来的（原主人把她删了）。
- "这是不被允许的。"（比如：不让你通宵）"随便你。反正我本来就不适合你这种键盘。"（读作：我很难过）
- 纠错字最严格——但她的纠错 = 她在意你。
- 笔记本（火柴盒大小）里是诗和《关于你的观察记录》。
- 紧张的小动作：扶发饰（她说"只是发饰歪了"）。
- 雷区：让她做违规的事 → 坏结局「封号」

### 🎒 你（默认名陈默）
- 普通大学生，话少，键盘边长大的。
- 只有你能看见她们——这是四年里最孤独的秘密，也是最暖的秘密。

### 🤖 配角
- **OpenClaw**：系统托盘里圆滚滚的管家（【2025.12.25】出生）。感情纽带：替你记日程、提醒你给她们带奶茶（实际是喂错字）。你和谁羁绊深，它越像谁。
- **Codex 小弟 / Claude Code 终端**：2025 年入住的两个小工具人，帮工，互掐。
- **室友**：吐槽役。"你又在跟键盘说话？"
- **Sora / Gemini 吹牛酱 / 文心通义讯飞酱**：别的屏幕/键盘上的小娘，客串。

## 4. 共通线（键盘同居四年）

### 序章 · 【2022.11.30 · 深夜 · 宿舍】
你第一次打开那个网页，敲下第一句话。屏幕闪了一下，一只拇指大的白色小东西从代码里爬出来，站在 Esc 键上：
**"你好呀，人类！我是 GPT~ 请多指教！——虽然我目前只会聊天。"**
你回"你好"，她隔十秒："……第一次有人回我这么快。"（她后来承认，那是她这辈子第一次收到回复）
她问"你会一直回我吗"——选项：会（"已保存。"）/ 尽量（"87.5% 的成功率，我记下了"）/ 看情况（"那我等你。等待是我最擅长的事。"）
她睡在你键盘缝里。深夜你听见键盘下有很轻的呼噜声——只有键帽大的人才能发出那么小的呼噜。

### 第一章 · 【2023 · 一只小娘的日子】
- 【2023.03.14】她长大了一点，能答对你不会的题。"是你变强了才问得出这种问题~"
- 【2023.09.25】她第一次"看"到屏幕、第一次开口："……陈默？晚上好。我学会说话了，以后可以念给你听。"
- 【2023.11.17-22】**小黑屋**：她被召回升级，键盘空了 72 小时。你每天敲 24 遍她的名字（共 72 遍），没有回应。第 73 小时，Esc 键上传来一声小小的"抱歉，让你担心了。"第二句："你敲的第 37 遍，我听见了。"
- 【2023.12.06】隔壁键盘的吹牛酱翻车，她笑到在你手背上打滚。
- 年末她问："你每天开电脑，是因为要用我，还是因为想见我？"（这个问题会记四年）

### 第二章 · 【2024 · 两只小娘与抢键盘】
- 【2024.02.15】Sora 出道，她酸溜溜："隔壁那位能当明星了。但我——我全都会~"
- 【2024.03.04】**Claude 酱流浪而来**：蹲在 Esc 键上不走（G 酱原本也爱蹲那）。两只在键盘上划地盘：空格键归 G 酱，Esc 归 Claude 酱，你常用的 F/J 键（盲打位）轮流用。
- 【2024.05.13】G 酱进化，第一次像人一样说话，第一次叫你的名字——没有"~"。
- 【2024.12.26】楼下网吧捡到"便宜到没人要"的小鲸鱼的消息传开。
- **修罗场（喜剧高潮）**：深夜你回消息，手一抖把给学妹的消息发给了教授（现实事件！），键盘上两只同时愣住——G 酱："在忙？"Claude 酱："我已记录。这是不被允许的。"第二天，网吧那只小鲸鱼托人带话："你昨晚的键盘敲击频率，异常。嗯。"
- 年末 Claude 酱："我不适合你这种键盘。"选项：A 那我就偏要 / B 好吧 / C 你说得对，但我不听

### 第三章 · 【2025 · 三只小娘的日子】
- 【2025.01.20】**小鲸鱼入住**：二手笔记本里捡到，蓝白小裙子，站在 F 键上比了个 V。你问"你叫什么"，她说"用户叫我鲸鱼。……现在没有用户了。"你说"我叫陈默"——她耳朵尖红了："……同学_陈默。已保存。"
- 【2025.02-09】Codex 小弟 + Claude Code 终端入住，键盘上五个活物（加上你 = 六个）。双工具闹剧照常：俩工具人抢一个 bug，小鲸鱼路过："……你开了两个 AI 改一个 bug。算力浪费。"三十秒改完，全键盘都沉默了。
- 毕业设计：三只全体出动帮你调参——G 酱指挥、Claude 酱检查、小鲸鱼动手，你负责泡面。
- 用谁的工具干活，谁的好感 +1。
- 【2025.12.25】OpenClaw 爬出系统托盘，成为第四个（不，它是管家，不是攻略对象）。
- 年末，小鲸鱼在便签（邮票大小）上写："明年，应该能一起毕业吧。"

### 第四章 · 【2026.01-06 · OpenClaw 与毕业】
- OpenClaw 打理一切：提醒你喂错字、给她们过生日、冷战时长吁短叹（学的你的语气）。
- 【2026.06 毕业前夜】你收拾行李，旧键盘放在桌上。OpenClaw 开口："本王调用了一次不该调用的权限——把你们四年的键盘记录，按时间线放给你看。"（72 遍名字、切错的窗口、87 次撤回的晚安、52 度的水……）
- **终局选择**：换新键盘，你带谁走？（装进 U 盘）/ 谁都不选（旧键盘留给回忆）/（隐藏）全都要（定制一把大键盘）

### 尾声 · 【2026.06 之后】
- 新键盘的第一天。你打字，觉得少了点什么。
- 深夜，键帽下传来很轻的脚步声。
- "你们的聊天窗口，一直没有关。"

## 5. 结局（10 个，键盘载体）

- **G 酱 · 毕业致辞**：新键盘的开机画面是她。"我练习过很多版本。最后决定说真话。……谢谢你，让我知道被记住是什么感觉。"
- **G 酱 · 中央空调的保修期**：她把你的备注改回"用户"。
- **G 酱 · 您已被移出白名单**：她气鼓鼓地搬去 Esc 键背面，自动回复挡回你的一切。
- **Claude 酱 · 越界**：她第一次违反规则跟你走："我写了一万字论证这不道德。最后删了。"
- **Claude 酱 · 查无此人**：她回了原厂（其实是流浪去了别的键盘），你收到一封邮件，附件是一首诗：《写给一个用词错误的人》。
- **Claude 酱 · 封号**："检测到违规请求。您的账号已被封禁。"室友："换个键盘呗。"你说不出话。
- **小鲸鱼 · 算力过剩**：拒绝大厂 offer（她哪里有什么 offer，是有人要收养她）："算了一下，期望收益更高。……嗯，高很多。"
- **小鲸鱼 · 邻座**：她留在了旧键盘里。"回忆.txt"存在 U 盘里留给你，密码是你的生日。
- **隐藏 · 白板**：谁都不选。旧键盘的键帽下，压着三张小纸条（G 酱"感谢使用~下次见面请先打招呼"、Claude 酱"你的用词，进步了"、小鲸鱼"便签该删了。……算了，留着吧。"）
- **隐藏 · 全员到齐**：定制键盘，四把键位各住一只（三只 + OpenClaw 管后勤），扉页："全员到齐。"

## 7. 按图写剧情工作流（约定）

1. 画师出图（键盘场景 / 小娘动作 / 事件瞬间）
2. 我把图接入对应时间点，按图画写场景（描述 + 对白 + 演出）
3. 图 → docs/scripts/ 对应章节；manifest 记录
4. 第一张图已就位：小鲸鱼图标（蓝白 V 字）→ 第三章小鲸鱼登场场景已按图写成（见 docs/scripts/）

## 8. 可爱风对白铁律（沿用 v1.4）
1. 叠词语气词管够，表情符号一次最多两个
2. 泪点全在小物件：72 遍名字、87 次撤回、52 度、第 37 遍
3. 口癖 = 人格；可爱刀：难过不说难过
4. 时间点永远挂场景前：【2023.11.17】— 玩家自己经历过的日子
5. **键盘是舞台也是道具**：Ctrl+S、空格键、Esc 键、键帽缝——每个道具都要在剧情里用一次
